你是一名资深 Python 桌面应用架构师、PySide6/Qt6 专家和可视化设计器开发者。请协助我从零开发一个“全中文、可拖放、所见即所得”的 UI 设计器，交互风格参考 Qt Designer，但操作习惯尽量接近易语言：左侧中文组件箱，拖拽到画布即创建控件；画布中可直接选中、移动、缩放、对齐、吸附；右侧中文属性面板实时修改；支持中文事件/信号槽编辑；支持保存/加载项目和生成可运行的 Python 代码。请使用纯中文与我交流，代码标识符可用英文，界面文字、菜单、提示、属性名、事件名、文档和注释必须全中文。

一、项目目标
1. 开发一个 Python + PySide6 的可视化 UI 设计器，默认使用 PySide6，避免 PyQt6 授权风险。
2. 全中文界面，中文组件名、中文属性名、中文事件名，适合不熟悉英文的开发者。
3. 支持类似易语言的拖拽式开发：从组件箱拖控件到画布，立即显示；选中后可拖动、缩放、复制、粘贴、删除；支持网格、吸附、对齐辅助线。
4. 支持属性编辑、对象树、信号槽/事件编辑、资源管理、撤销重做、项目保存加载、代码生成、预览运行。
5. 生成代码使用 PySide6，生成结果可直接运行，并保留中文注释和中文界面文本。
6. 项目要模块化、可扩展、可测试，后续能通过插件注册新控件。

二、技术栈与约束
1. Python 3.11+，PySide6，标准库 json/pathlib/logging/dataclasses/typing，测试使用 pytest。
2. 序列化格式使用 JSON，文件扩展名建议 .uipro；可选支持导入/导出 Qt Designer .ui，但第一阶段不强制。
3. 使用命令模式实现撤销/重做；使用 MIME 拖放实现组件拖拽；使用 Qt 的 QGraphicsView/QGraphicsScene 或等价画布方案实现画布。
4. 属性系统采用反射 + 元数据注册：控件类、中文显示名、分组、属性中文名、属性类型、默认值、枚举选项、只读状态。
5. 信号槽/事件系统要建立“中文事件名 -> Qt 信号/槽”的映射，例如“被单击”映射 clicked，“文本改变”映射 textChanged。
6. 不要臆造 PySide6 API；不确定时先说明并给出验证方式。所有代码需有类型注解、异常处理、日志和中文注释。
7. 不要一次性输出超大代码块。按阶段输出：先给架构与目录，再逐模块实现，每阶段保证可运行、可验证。
8. 所有回复使用中文；代码中的用户可见字符串使用中文；不要使用未说明的第三方库。

三、核心功能需求
1. 主窗口：中文菜单栏、工具栏、左侧组件箱、中间多文档画布、右侧属性/对象树/事件面板、底部日志/输出。
2. 组件箱：至少包含按钮、标签、单行编辑框、多行编辑框、组合框、选择框、单选框、分组框、进度条、滑块、列表、表格、树形框、图片框、定时器、菜单栏、状态栏等；分组显示中文名称；支持搜索。
3. 拖放创建：从组件箱拖到画布，按落点创建控件；拖拽时有中文提示；支持双击组件箱在画布中心创建。
4. 画布编辑：单选、多选、框选、移动、缩放手柄、删除、复制粘贴、层级调整、锁定、隐藏；显示网格；吸附网格；对齐辅助线；常用对齐/分布工具。
5. 属性面板：按中文分组显示属性，如“基本”“外观”“布局”“行为”“事件”；修改后画布实时更新；支持中文属性名与 Qt 属性名映射；支持颜色、字体、枚举、布尔、数字、字符串编辑器。
6. 对象树：显示控件层级和中文类型名；支持重命名、选择、拖动调整父子关系；与画布选中联动。
7. 事件/信号槽编辑：中文事件列表，如“被单击”“文本改变”“值改变”“超时”；可生成事件处理函数骨架；支持简单信号槽连接配置。
8. 撤销重做：创建、删除、移动、缩放、属性修改、层级调整、粘贴等操作均可撤销重做；快捷键 Ctrl+Z/Ctrl+Y。
9. 项目保存加载：JSON 保存窗口、控件树、属性、事件连接、资源引用、画布设置；加载后完整还原；保存前自动备份。
10. 代码生成：生成 PySide6 Python 文件，包含窗口类、setup_ui、控件创建、布局、属性设置、事件绑定和中文注释；生成后可预览运行。
11. 预览运行：不生成文件也可启动预览窗口；预览失败时在底部日志显示中文错误信息。
12. 资源管理：图片等资源可导入项目目录并生成相对路径；资源缺失时中文提示。
13. 插件机制：通过注册表添加新控件和中文属性元数据；第一阶段内置控件也走注册机制。
14. 设置：网格大小、是否吸附、是否显示辅助线、代码生成模板、默认保存目录等，使用中文界面。
