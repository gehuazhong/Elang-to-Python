# 中文可视化界面设计器

本项目使用 Python 与 PySide6 开发全中文、可拖放、所见即所得的桌面界面设计器。设计交互参考 Qt Designer，工作台采用 VS Code Dark Modern 风格，突出中文组件、中文属性、中文事件和即时反馈。

## 当前阶段

当前版本为 **0.10.2 开发预览版**，面向习惯易语言拖放设计的个人开发者。组件箱已接入七十二类组件，最前面的“常用组件”集中提供按钮、标签、编辑框、单选框、分组框、画板、列表框、时钟、通用对话框、图片框、选择夹、选择框、组合框、超级列表框、工具条和状态条。

0.10.2 修复保存重开后重复生成相同导出版本、事件初始化失败后残留窗口、通用对话框回调重开与释放异常，以及标签栏刷新时丢失选择和业务数据的问题。关闭运行窗口会清理通用对话框并停止时钟；取消关闭时保留正在进行的操作。操作与验证见 [0.10.2 迭代记录](docs/0.10.2迭代与验证.md)。

0.10.1 修复整组复制后的对话框触发关系，支持在对象树中按 Ctrl 多选时钟、输入对话框等非可视组件，以及多个停靠窗口，并整组复制、粘贴、删除和撤销。对话框结果回调可以立即打开下一次对话框；进度框每次任务只报告一次完成或取消，重新打开恢复初始进度。同时缓存不可变的组件默认属性，减少大型界面的构建计划开销。操作与验证见 [0.10.1 迭代记录](docs/0.10.1迭代与验证.md)。

工作台已统一为深色侧栏、编辑区、蓝色选中与状态栏。左侧活动栏可显示或隐藏组件箱、对象树、属性及输出；按 `Ctrl+Shift+P` 搜索现有菜单命令，支持方向键、回车和 Esc。关闭所有项目后可从空工作区新建或打开项目。主题只影响设计器，设计窗口、独立预览和导出程序继续使用项目自己的配色。截图、细节与验证命令见 [VS Code 风格工作台](docs/VSCode风格工作台.md)。

菜单栏新增 **设置 → 工作台设置…**，快捷键为 `Ctrl+,`。可调整本软件的字体、8–20 磅字号、界面间距、工具栏图标、文档标签位置、面板显隐与停靠位置，以及工具栏、面板入口栏和状态栏。提供标准、紧凑侧栏、右侧组件箱、专注画布四种布局；支持即时预览、应用保存、取消还原和恢复默认，重启后保留设置。操作与截图见 [工作台设置](docs/工作台设置.md)。

修复“打开项目”文件过滤器使用全角括号、导致已有项目被错误隐藏的问题。打开和保存使用统一的项目扩展名规则，诊断包的 ZIP 筛选也已修正；打开时增加“所有文件”选项。反复进入目录、列表和详细视图、中文路径及取消操作均有回归覆盖，见 `docs/项目文件选择与验证.md`。

表格和超级列表框支持 **各列自定义宽度**。打开“表格内容”或“表项与列”，选择“当前列”并输入“列宽”，或直接拖动列标题边界；可使用“适应内容”和“恢复默认”。例如 ID 设为 56、名称设为 160、说明设为 280。列宽随内容保存，复制、撤销、预览和导出均保留；设了明确宽度的末列不再自动拉伸。操作和验证见 `docs/自定义列宽与验证.md`。

属性面板的 **事件** 已改为勾选开关：勾选连接，取消勾选断开，默认不连接。状态随项目保存，支持撤销、重做和组件复制。七十二类组件及窗口、工作区、选择夹页面已补齐原生信号；可视组件另有鼠标、键盘、焦点、显示隐藏、关闭、重绘和拖放事件。预览只报告勾选项，导出会自动连接 `event_handlers` 目录中的对应处理函数，已有业务文件不会被覆盖。操作与验证见 `docs/事件勾选与验证.md`。

“窗口属性 → 窗口”新增 **程序图标**。点击“选择…”可导入 ICO、PNG 等图标或图片，属性区显示缩略图，画布标题栏立即更新。支持清除、撤销和重做；多尺寸 ICO 采用分辨率最高的一帧，保留透明背景。图标作为静态快照随项目保存，预览和导出均生效，原文件移动或删除后仍可使用。操作与验证见 `docs/程序图标与验证.md`。

属性区已统一滚轮交互：滚动只浏览面板，不会误改数值、尺寸、日期或下拉选项；展开列表后仍可滚动选项，键盘和步进按钮照常使用。工具栏缩放选择同样防误触。此保护不改变预览及导出程序的原生控件行为。

本轮还修复了步进输入被后台刷新覆盖、取消弹层后属性停留在旧值、面板销毁后延迟刷新异常，以及父容器锁定未同步禁用子控件尺寸编辑的问题。项目保存与加载统一采用三十二兆字节容量边界，超限时保留原项目和备份。修复依据、验证命令和适用范围见 `docs/属性交互与稳定性审计.md`。

持续检查还定位并修复了取消延迟刷新后保留面板引用，以及保存确认、恢复项目和“关于”对话框关闭后仍被保留的问题。压力工具逐轮核对面板、画布和文档包装对象是否释放，避免仅凭原生窗口销毁就判断资源清理完成。

窗口跟随拉伸复用已验证的属性计划，按尺寸变化更新绘制缓存，松手直接提交当前画面，失败或取消时还原。启动尺寸根据当前屏幕的可用逻辑范围调整；新工作台在可用高度不足六百二十时，将组件箱与对象树合并为标签区并收起输出，字体不变。已保存且有效的布局与窗口位置优先保留，输出仍可从“视图”打开。

“窗口属性 → 窗口”新增 **组件随窗口缩放** 开关。默认关闭；开启后，拉伸设计窗口、预览窗口或导出程序的窗口，会按比例调整组件的位置和大小，包含嵌套容器和选择夹页面。字号、容器边距、工具条及状态条高度保持设置值。画布拖动可实时查看，松开后整次撤销；预览拉伸不修改项目。说明见 `docs/窗口组件跟随与验证.md`。

属性中的“字体”和“字号”均改为下拉选择，无需手填。字体来自本机字库，中文字体优先并显示对应字形；字号列出常用值及其余一至九十六磅整数。两项都可选择“继承默认”，修改立即更新画布且可撤销。旧项目缺失的字体保留原名并提示。说明与验证见 `docs/字体字号选择与验证.md`。

新建和打开项目默认按 **100% 原始大小** 编辑，窗口靠近画布左上方；工作区放不下时使用滚动条，不再自动把窗口缩成小图。工具栏“原始大小”或 `Ctrl+0` 恢复正常比例和左上起点；“查看全貌”或 `Ctrl+9` 手动查看完整设计。普通滚轮只滚动，控制键加滚轮围绕鼠标缩放。调整工作台大小和切换标签不会重置查看比例，窗口尺寸与导出代码不受影响。详细说明见 `docs/原大画布编辑与验证.md`。

打开 `examples/易语言基础组件示例.uipro` 可体验这十六类基础组件。选择夹支持逐页拖入控件、切换、增删和整树复制；时钟与通用对话框显示在画布下方，设计时不运行。通用对话框的“触发按钮”属性可以直接选择按钮，预览和导出后点击即打开。工具条、状态条固定挂接窗口。图片作为静态快照随项目保存，导出后生成相对路径图片文件。

超级列表框本版提供报表式多列、整行选择、多选、勾选、排序、编辑和行高；尚无大图标、小图标显示模式。画板支持运行时鼠标绘画和绘图方法。完整操作与范围见 `docs/易语言基础组件与验证.md`。

需求依据为根目录的《起草项目架构.txt》。此前版本提供的边框容器、旋钮、滚动条、小数输入框、日期时间、日历、工具按钮、命令链接按钮和液晶数字继续保留；可在组件箱搜索中文名称。完整中文属性明细见 `docs/组件支持矩阵.md`。

从“帮助 → 组件支持清单”可搜索中文组件、属性和事件，也能查看尚未接入的组件。`docs/组件支持矩阵.md` 按本机 PySide6 6.11.1 核对七十三个 QWidget 体系类，并另列非可视对象、布局和常用扩展模块；其中包含基类和内部辅助类，不能把七十三当作可拖放组件总数，也不代表整个 Qt 的全部组件。

打开 `examples/容器与日期示例.uipro` 可体验分组嵌套、日期、小数和日历。向分组框或边框容器内容区拖放可创建子控件；通过“所属容器”属性或右键“移入容器”调整父级。复制容器会复制全部后代，撤销一次恢复整次操作。子坐标相对内容区，内边距决定内容起点。实现和验收见 `docs/容器与扩展组件验证.md`。

打开 `examples/常用组件示例.uipro` 可直接体验十三类组件。多行文字、列表项目、表格和树形内容在属性面板中点击“编辑…”修改；表格可增删行列和修改列标题，树形内容可增删同级、子级及调整顺序。确认后整次修改可以撤销。

对象面板支持层级显示与多选联动，画布支持网格吸附、查看缩放、单对象缩放手柄及整组键盘微调。父级可通过属性和右键调整，选择夹页面可通过页签切换。自动布局通过水平、垂直、网格和表单布局容器提供。对象树拖动改父、内置业务代码编辑器和集中资源库仍待实现。同级控件支持批量排版，多选不提供整组缩放或批量属性编辑。

“排版”菜单和多选右键菜单支持 **等宽、等高、等宽高**。选择同一容器内至少两个可自由定位的控件，以最后选中的控件为基准统一对应尺寸，位置保持不变；属性面板显示当前排版基准。支持一次撤销、重做、保存和导出；若结果超出父容器或不满足组件尺寸要求，整次操作不生效。锁定控件和自动布局中的控件不能使用这些操作。

“文件 → 导出 Python 项目”或 `Ctrl+Shift+E` 可导出独立运行目录，勾选事件的业务逻辑写入 `event_handlers` 中的对应函数，窗口初始化及手动连接仍可写入 `handlers.py`，重复导出保留已有业务文件。导出使用完整版本目录与原子指针切换，包含未知能力时会明确阻止，避免静默丢失。基础导出流程见 `docs/商业化基础与验证.md`。

界面已优化为组件箱与对象树在左、属性在右的布局。画布显示设计窗口的标题栏和边框，支持窗口按钮、边框类型、置顶、背景色、文字颜色及字体编辑；操作方法见 `docs/界面优化与窗口属性.md`。

当前视觉以 [VS Code 风格工作台](docs/VSCode风格工作台.md) 为准。早期中性灰方案的 `docs/工作台视觉规范与验证.md` 保留为历史记录。

选中控件后可拖动手柄调整大小，主窗口可拖动右边、下边或右下角；位置和尺寸支持整次撤销。属性采用并排尺寸编辑，工具栏和空窗口提示进一步优化，详见 `docs/画布交互优化与验证.md`。

右键画布控件、非可视组件或对象树可复制、粘贴、删除。`Ctrl+C` 复制，`Ctrl+V` 粘贴，`Delete` 删除，`Ctrl+Z` 恢复。普通控件支持同级整组，容器和选择夹支持整树跨文档复制；单独页面请复制所属选择夹。工具条和状态条每窗各一个，已有时拒绝重复粘贴。复制通用对话框会清除外部触发按钮绑定并提示，粘贴后可重新指定。

组件箱的“常用组件”中提供“编辑框”，搜索“单行编辑框”也可找到。支持文本、占位文本、最大长度、只读、密码显示、清除按钮、边框、对齐方式和通用外观属性；设计时通过属性面板设置初始内容，按 `F5` 后可实际输入。用法、验证与限制见 `docs/单行编辑框与验证.md`。

已完成一轮交互与故障路径排查：非法属性会保留输入并就地提示，回车提交后保留焦点；文本与设计文档分别撤销重做，对象树刷新保留折叠状态。绘制缓存重试、缩放失败恢复、恢复目录异常和剪贴板校验也已补齐，详见 `docs/全量排查与修复记录.md`。

点击“预览”或在设计器内按 `F5`，无需保存即可在独立进程中运行当前界面。修改后再次预览可更新内容；`Shift+F5` 停止，预览窗口内 `Esc` 关闭（快捷键录入时交给录入组件，弹出菜单与下拉列表优先关闭自身）。当前支持七十二类组件；勾选事件触发时显示中文提示，时钟、重绘和鼠标移动等高频提示按秒合并，实际事件仍正常处理。预览不执行导出目录中的业务代码。

## 启动

在项目根目录执行：

```powershell
python -m pip install -r requirements-dev.txt
python -X utf8 main.py
```

也可以在开发工具中直接运行根目录的 `main.py`。原有命令 `python -m app` 继续可用，两种入口复用同一套启动逻辑。

启动时可传入一个或多个项目路径，例如 `python -X utf8 main.py "examples/第二阶段示例.uipro"`。

仅运行应用可安装 `requirements.txt`。已有对应依赖时无需重复安装。打开 `examples/第二阶段示例.uipro` 可以检查本阶段完整支持的窗口。

当前修改文件清单、操作步骤、实测结果与限制见 `docs/易语言基础组件与验证.md`；此前各阶段文档保留历史记录。

## 独立环境运行

需要隔离依赖时，可以使用以下命令：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -X utf8 main.py
.\.venv\Scripts\python.exe -m pytest -q
```

运行依赖仅使用 PySide6；开发测试增加 pytest。其余使用 Python 标准库及随 PySide6 提供的 Qt 模块。
