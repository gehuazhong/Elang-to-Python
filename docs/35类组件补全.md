# 35 类组件补全

组件箱现有 **72 类可创建组件**，注册表共 77 项。原支持清单中的 35 项待接入能力已接入；10 个抽象基类和内部辅助类继续标记为非独立组件。工作台沿用 VS Code Dark Modern 风格。

| 分类 | 新增组件 |
| --- | --- |
| 自动布局，5 项 | 水平布局、垂直布局、网格布局、表单布局、弹性空白 |
| 容器，6 项 | 滚动区域、分隔容器、堆叠容器、折叠页容器、多文档区域、向导页面 |
| 窗口，6 项 | 对话框窗口、停靠窗口、多文档子窗口、向导窗口、启动画面、独立选项卡栏 |
| 对话框，6 项 | 消息框、错误消息框、输入对话框、颜色对话框、字体对话框、进度对话框 |
| 数据视图，5 项 | 列表模型视图、表格模型视图、树形模型视图、分栏视图、撤销历史视图 |
| 分组，2 项 | 对话框按钮组、非可视按钮组 |
| 图形扩展，5 项 | 图形视图、硬件渲染控件、OpenGL 绘图控件、SVG 矢量图、网页控件 |

## 设计与布局

在组件箱搜索中文名称，双击创建或拖入容器。所有组件的声明属性、事件连接及嵌套关系均保存到项目，支持撤销、重做和独立 Python 导出。完整属性和事件见 [组件支持矩阵](组件支持矩阵.md)。

四种布局以可选中的布局容器表示，内部使用真正的 Qt 布局。子控件按对象顺序排列，原几何作为设计数据保留；画布显示 Qt 计算后的实际位置和尺寸。布局托管的子控件不再提供自由拖动、尺寸手柄和批量对齐，使用“布局项”设置顺序、伸缩、行列和跨度，仍可通过“所属容器”移出布局。网格行列从零开始，负一表示自动排列；重叠会阻止提交。表单按相邻的标签、字段两项配对。弹性空白在运行时透明。

滚动区域可以设置内容尺寸、滚动条策略以及初始滚动位置；通过初始滚动属性查看和编辑超出视口的内容。分隔容器在运行时可以拖动分隔条，初始分区尺寸按对象顺序填写。

堆叠容器、折叠页容器和向导自动建立页面。右键容器或页面可以添加、删除页面；选择对象树中的页面或其子控件时自动切换到对应页，也可从“当前页面”属性选择。页面随所属容器整树复制。直接创建向导页面时，会使用所属向导或创建新向导。

停靠窗口挂在主窗口边缘，用初始宽高和停靠位置控制布局，支持运行时浮动。多文档区域容纳多文档子窗口；直接向区域添加普通控件时，会先建立子窗口。整个区域或子窗口均可连同后代复制。

## 运行接口

对话框窗口、向导和启动画面在画布中保留设计位置，运行时作为独立窗口显示。设置“运行时自动显示”或“触发按钮”，也可在导出业务中调用 `open_dialog()`。对话框按钮组的确定、取消默认控制所属对话框，可关闭此行为。

六种专用对话框是非可视服务，显示在画布下方。它们不会在设计时弹出；预览或导出后，触发按钮调用真实 Qt 对话框。`accepted` 返回输入值、颜色字符串、字体字符串或消息框按钮结果，`cancelled` 表示取消。打开期间可通过 `native` 访问原生对象；进度对话框可用 `setValue(value)` 更新进度。关闭主窗口时清理运行资源。

模型视图提供可编辑的 `QStandardItemModel`，业务可通过 `data_model` 或 `model()` 访问，也可使用原生 `setModel()` 替换。表格内容包含独立列宽。撤销历史视图提供自己的 `undo_stack`，供运行程序压入 `QUndoCommand`；它不会显示设计器自身的文档历史。

非可视按钮组使用成员的代码名称建立关系，可跨父容器分组。每个按钮只属于一个显式组，成员 ID 从零开始；勾选互斥时最多一个成员选中。删除按钮会清理引用。复制独立按钮组会清除外部成员引用，粘贴后重新指定。

图形视图持有 `graphics_scene`；SVG 使用项目内嵌的 `svg_data`。OpenGL 和 RHI 控件支持清屏颜色、多重采样和初始化、绘制、失败信号，通过 `native` 访问运行表面。RHI 使用 OpenGL 后端，以便与 OpenGL 和网页控件在同一窗口共存。

网页控件支持内嵌 HTML 或 URL、JavaScript 开关、缩放及加载事件。设计器显示静态标识，预览或导出时才建立真正的 `QWebEngineView`，通过 `native`、`native.page()` 调用浏览器接口。Qt 图形模块由已规定的 PySide6 6.11.1 提供，发行配置包含新增运行模块和布局算法。未重新生成历史便携包。

## 验证

新增专项测试涵盖全部 35 项的创建、画布缓存、数据往返、复制、撤销、磁盘保存与导出；同时检查布局子控件不重叠、删除后的所有权、跨容器按钮互斥、输入结果和对话框确认、网格冲突及撤销栈行为。

```powershell
python -m pytest tests/test_advanced_components.py -q
python -m pytest -q --junitxml=reports/components-completion/pytest.xml
python -X utf8 main.py --release-check reports/components-completion/release-check.json
python scripts/check_advanced_native.py --mode preview
python scripts/check_advanced_native.py --mode export
```

Windows 实机检查同时放置网页、OpenGL、RHI、SVG 和图形视图：验证网页加载、JavaScript 返回 42、两种图形表面的实际像素及初始化和绘制信号。预览和独立导出均通过，结果及截图见 `reports/components-completion`。其中的 `扩展组件示例.uipro` 可在设计器打开，`graphics-export/main.py` 可独立运行。

另提供 [自动布局与高级容器示例](../examples/自动布局与高级容器.uipro)，包括布局顺序、模型视图、折叠页、滚动区域、停靠窗口与多文档子窗口。用 `python scripts/capture_completed_components.py` 可重新生成工作台截图；已有示例文件会保留。

这些支持范围以公开的属性和接口为准，不等于暴露 Qt 每个类的全部 API。旧格式的 `node.layout` 自动布局数据仍按原兼容规则处理，新项目请使用组件箱中的布局容器。
