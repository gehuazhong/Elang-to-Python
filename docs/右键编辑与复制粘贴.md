# 右键编辑与复制粘贴

记录日期：2026 年 11 月 7 日。

本次补齐当前按钮、标签的右键复制、粘贴和删除。画布、对象树与“编辑”菜单共用同一套文档命令，不新增运行依赖。

## 操作方法

1. 左键点击画布中的按钮或标签即可选中，选中后按 `Delete` 删除，按 `Ctrl+Z` 恢复。
2. 右键点击控件会先选中该控件，再打开“复制、粘贴、删除、撤销、重做、窗口属性”菜单。
3. 选中控件后按 `Ctrl+C` 复制，按 `Ctrl+V` 粘贴；也可使用右键菜单或主菜单“编辑”。
4. 在画布空白处右键选择“粘贴”，控件按右键位置放置，并遵循网格吸附和窗口边界。
5. 左侧对象树同样支持右键复制、粘贴、删除。选中树中的控件后按 `Delete` 也能删除。
6. 属性输入框内的复制、粘贴、删除继续处理文字，不会删除画布控件；“编辑”菜单也按文本焦点处理。

普通快捷键粘贴从源位置向右、向下偏移十六个逻辑像素，连续粘贴逐次增加偏移；靠近窗口边缘时限制在可用边界内。副本自动生成唯一名称和代码名称，并选中新控件。跨文档粘贴、关闭源文档后再粘贴均可用。

主窗口和工作区不允许复制或删除；锁定控件禁用删除；只读文档允许复制但不允许粘贴或删除。不可用操作在菜单中显示为灰色。空剪贴板会禁用粘贴，损坏或不兼容的控件数据会显示中文错误，保持模型与撤销历史不变。

## 实现边界

剪贴板使用独立 MIME 类型和第一版 JSON 控件片段，最大一兆字节，不保存控件实例，也不执行代码。片段只包含选中的控件及其必要事件声明，不包含整个项目。

粘贴复用项目结构和属性校验，生成新的控件标识、名称、代码名称、事件连接标识及处理函数声明标识，再通过文档一次提交。控件标题、尺寸、颜色、字体、可见及设计状态保留；复制锁定或设计隐藏的对象时，副本也保留该状态。

当前单对象复制保留指向自身的槽连接及关联处理函数声明；与其他控件关联的外部连接不复制，并报告数量。处理函数只复制声明，不包含外部业务代码。粘贴和删除都完整参与撤销重做，删除会移除对应事件连接及焦点引用，撤销恢复原始标识和数据。

右键菜单打开后若切换文档或修改了对应模型，旧菜单不能继续操作新文档。复制前提交尚未完成的属性输入；输入校验失败时保留输入并停止操作。

本次支持当前内置按钮与标签的单对象复制。多选、容器子树、活动布局、图片资源迁移及未知插件扩展不在本次范围内；遇到尚未支持的数据会明确拒绝，不生成缺失内容的副本。

## 运行与验收

在项目根目录执行：

```powershell
python -X utf8 main.py
python -X utf8 -m pytest tests/test_clipboard.py -q
python -X utf8 -m pytest -q
python -X utf8 -m tests.check_clipboard
```

完整回归为 246 项通过，耗时 24.61 秒，包含本次 33 项专项。专项覆盖右键命中、四档缩放下的粘贴落点、对象树快捷键、文本焦点与真实菜单操作、跨文档及源文档关闭后的粘贴、名称冲突处理、事件重映射、保存加载、删除恢复、历史预算拒绝、损坏数据、只读与锁定状态、独立预览及过期菜单保护。

Windows 桌面检查通过，设备像素比为 1.0。通过实际弹出菜单和合成点击复制按钮，在 `(280, 160)` 粘贴副本，再删除原控件并撤销恢复。复制后关闭整个独立测试进程的退出码为零。
