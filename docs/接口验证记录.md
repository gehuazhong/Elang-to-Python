## 已完成的运行时接口探针

探针使用临时离屏 Qt 应用，在内存中创建窗口和控件，结束后释放；未启动完整设计器。

| 检查 | 实际结果 | 对架构的影响 |
| --- | --- | --- |
| `QMetaObject.indexOfProperty("text")` 与 `QMetaProperty.isWritable()` | 按钮文字属性存在且可写 | 可以核验中文标题到 `text` 的映射 |
| `QMetaProperty.write()` | 返回真，按钮文字读回“确认” | 简单属性反射路径可用 |
| 根窗口嵌入 `QGraphicsScene` | 成功取得根代理 | 根代理承载窗口的方案可行 |
| 嵌套按钮的 `subWidgetRect()` | 与按钮映射到根窗口的位置一致 | 选框可从真实层级取得位置 |
| `QGraphicsView.mapToScene` | 接口可调用 | 可建立视口到场景的坐标转换 |
| `button.clicked[bool]` | 可以连接，普通单击收到假值 | 中文“被单击”明确绑定布尔参数签名 |
| `QUndoStack.push()` | 一次压栈执行一次 `redo()` | 创建命令不能在压栈前重复修改模型 |
| 撤销与重做 | 计数从一变零，再恢复一 | 基础回放机制可用 |
| 保存点 | 修改后未保存，撤销回保存点恢复已保存 | 使用保存点维护文档脏状态 |
| `issubclass(QTimer, QWidget)` | 假 | 定时器放入非可视组件区 |
| `QMainWindow` 默认的 `closed` 属性 | 不存在 | 窗口关闭需要事件适配 |
| `QPushButton` 默认的 `doubleClicked` 属性 | 不存在 | 通用双击需要事件适配 |
| Qt 中文翻译文件路径检查 | 文件存在 | 下一阶段可以实际安装翻译器 |

这些检查验证接口存在及最小行为。中文翻译文件存在不等于所有对话框已经完成中文验收。

## 数据示例验证范围

本阶段对两个示例执行以下核对：

- UTF-8 JSON 语法与中文往返。
- 项目对象的标识符、名称、代码名称和同级顺序唯一。
- 根窗口和工作区关系正确，父级引用存在且无循环。
- 几何矩形有效，定时器没有可视矩形。
- 事件源、处理函数、目标槽和参数类型与示例元数据对应。
- 元数据中声明的 Qt 属性存在，声明为可写的属性可写。
- 示例中的信号签名和槽方法存在，枚举选项对应真实 Qt 成员。

这属于第一阶段契约探针，不是尚未实现的项目加载器或注册器的测试。

本次通过的数量：项目节点五个、事件连接两条、处理函数声明一个、示例控件类型三个。完成十九次元属性核验、两次信号签名核验、五次槽方法核验和六次枚举成员核验。相同公共属性在不同控件上分别核验，因此十九次不表示十九种不同属性。

重新执行 JSON 语法检查：

```powershell
python -X utf8 -m json.tool "examples/中文界面示例.uipro"
python -X utf8 -m json.tool "examples/控件元数据示例.json"
```
