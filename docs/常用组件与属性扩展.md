# 常用组件与属性扩展

版本：0.5.0 开发预览版。验证环境：Windows、Python 3.11.8、PySide6 6.11.1，日期为 2026 年 11 月 7 日。

## 本轮目标与范围

将组件箱从三类扩展到十三类，让新增组件具备完整的中文属性编辑、画布操作、文件往返、预览和独立代码导出。继续使用已有模型、命令和注册表，没有引入新的第三方依赖。

| 组件 | 注册属性数 | 主要专属属性 |
| --- | ---: | --- |
| 按钮 | 20 | 标题、可选中、已选中、平面样式、长按重复触发及时间 |
| 标签 | 19 | 文本、对齐、换行、内边距、缩进、边框样式 |
| 单行编辑框 | 21 | 文本、占位、长度、密码显示、只读、清除按钮、边框、对齐 |
| 多行编辑框 | 20 | 多行纯文本、占位、只读、换行、制表键、输入撤销、边框 |
| 组合框 | 20 | 列表项目、当前选项、允许输入、插入方式、下拉项数、重复项目 |
| 选择框 | 16 | 标题、允许半选、未选中／已选中／半选状态 |
| 单选框 | 16 | 标题、已选中、同容器互斥 |
| 数值输入框 | 24 | 最小值、最大值、当前值、步长、前后缀、循环、只读、调节按钮 |
| 进度条 | 21 | 数值范围、当前值、显示格式、文字、方向、反向显示、对齐 |
| 滑块 | 23 | 数值范围、步长、翻页步长、刻度位置与间隔、方向、实时更新 |
| 列表框 | 21 | 项目、当前选项、间距、换行、选择与编辑方式、交替行底色 |
| 表格 | 24 | 列标题与行数据、网格线、表头、行号、末列填满、选择范围与编辑方式 |
| 树形框 | 24 | 节点树、列标题、根展开按钮、默认展开、缩进、选择与编辑方式 |

注册属性数包含通用属性，不重复计入名称、代码名称及四项位置尺寸。通用属性包括启用、可见、提示文本、状态提示、布局方向、前景色、背景色、字体、字号、粗体、斜体、下划线和删除线。字体名称与字号仍分别编辑，没有新增完整字体对话框。

## 操作方法

运行项目根目录的入口，或使用新版便携包中的可执行文件：

```powershell
python -X utf8 main.py "examples/常用组件示例.uipro"
```

1. 从组件箱拖入组件，或双击添加；在画布选中组件后编辑右侧中文属性。
2. 多行文本、列表、表格、树形内容点击“编辑…”。按“确定”提交一次文档命令，按“取消”放弃草稿。
3. 列表允许空项目与重复项目，可增加、删除、上移、下移。项目索引从零开始，负一表示没有选中。
4. 表格支持增加／删除行列、上移／下移行；双击列标题改名，双击单元格编辑。标题和全部数据一并提交。
5. 树形内容支持增加同级／子级、删除节点、同级排序和修改文字。删除节点会连同子树一起删除，确认后的修改可撤销。
6. 右键菜单和快捷键沿用现有复制、粘贴、删除、撤销与重做；多选排版适用于全部十三类组件。
7. 按 F5 启动独立预览。编辑、选择和数值变化可实际交互，日志只提示中文对象名和事件名，不记录输入内容。
8. “文件 → 导出 Python 项目”生成独立目录。按导出说明安装 PySide6 后运行导出的 main.py，业务逻辑仍写入 handlers.py。

选择框是可多项勾选的控件；互斥单选框默认同一工作区只能选中一个。尚无可视化分组容器，因此当前不能在同一工作区中配置多个独立单选组。

## 数据与一致性

数值最小值不能大于最大值。缩小合法范围时，当前值自动调整到范围内；撤销同时恢复范围与原值。进度条上下限均为零时沿用 Qt 的不定进度效果。

删除组合框或列表框项目时，越界的当前选项自动调整。清空全部项目时设为负一。显式输入越界索引会被拒绝。

选中互斥单选框时，会取消同容器其他互斥单选框。复制已选中的互斥单选框也使用这条规则，新副本保留选中，原选项取消；粘贴撤销会一起恢复。关闭选择框的半选能力时，半选状态同步回到未选中。按钮设置已选中时自动启用可选中，关闭可选中时同步取消选中。

旧项目缺少新增属性时由注册表补默认值，节点版本保持不变。项目中的无效范围、越界索引或互相矛盾的选中状态会在文档提交及构建前给出中文错误，不依赖 Qt 静默修正。

集合属性采用真正的 JSON 数组和对象，不要求用户在属性面板手写 JSON。下面分别是列表、表格和树形内容的保存形态：

```json
{
  "items": ["选项一", "选项二"],
  "table_data": {
    "headers": ["名称", "状态"],
    "rows": [["任务一", "待处理"]]
  },
  "tree_data": [
    {"text": "工作项目", "children": [{"text": "任务一", "children": []}]}
  ]
}
```

这些字段分别属于不同组件。列表最多一千项；表格最多二百行、五十列；树最多一千个节点、十二层。集合单项最多一万字且不含换行，总文字最多二十万字。多行编辑框的文本最多十万字，统一换行编码。上述限制在项目校验和内容编辑确认时执行。

元数据默认值和文档集合值均递归冻结。画布、预览、导出使用同一份组件属性适配器；填充顺序为原生行为、集合内容、最终范围与选项值。复杂控件的视口及内部子控件进入画布缓存，避免表格和多行框只显示空边框。

## 已知限制

当前仍是开发预览版。分组容器、图片框和图片资源、定时器、菜单栏、状态栏尚未接入；没有用可视控件占位模拟这些能力。

树形内容节点是树形框的数据，不是对象树中的设计控件。表格和树形框采用轻量项目控件，暂不支持大型数据库模型、绑定查询或虚拟数据源。多行编辑框只处理纯文本，不解释富文本。

可视化事件／信号槽配置、自动布局、容器拖入、外部插件加载、整组缩放及批量属性编辑仍未完成。预览仅运行原生组件交互和中文事件提示，项目中的自定义业务事件尚不执行；导出业务可自行在 handlers.py 中绑定原生信号。

已有未知扩展、资源或尚未支持的事件配置仍会阻止导出，避免遗漏。桌面检查使用合成输入，未代替物理输入法、多屏显示缩放和独立干净系统验收。
