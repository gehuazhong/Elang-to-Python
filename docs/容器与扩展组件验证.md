# 容器与扩展组件验证

版本：0.6.0 开发预览版。环境：Windows、Python 3.11.8、PySide6 6.11.1；本机验证日期为 2026 年 11 月 7 日。

## 本阶段目标与实际范围

建立可核查的组件支持清单，并将可拖放组件从十三类扩展到二十五类。每类走同一注册表、文档命令、构建器和导出适配，避免画布能显示但保存或导出缺失。

本版新增分组框、边框容器、旋钮、滚动条、小数输入框、日期编辑框、时间编辑框、日期时间编辑框、日历、工具按钮、命令链接按钮和液晶数字。每类注册十六至二十四项属性，另有名称、坐标、尺寸和所属容器编辑；共五百一十条组件属性注册，其中包括各组件重复具备的通用属性，不等于五百一十种独立属性。

“帮助 → 组件支持清单”与《组件支持矩阵.md》覆盖本机 QtWidgets 模块七十三个 QWidget 体系类，并额外列出常见非可视对象、自动布局和扩展模块。抽象类、内部辅助类和窗口专属结构分别标明，不把所有 Qt 类当作组件箱的拖放目标。新增注册并不表示已经暴露原生类的全部属性。

## 容器规则

分组框和边框容器可嵌套，子控件坐标相对内容区左上角。模型内边距、原生 QWidget 的内容边距、画布子图元原点和导出后的坐标保持一致。分组框修改字体或样式时，Qt 会重新计算默认边距；专用容器适配类在相关事件后恢复显式边距，避免预览位置与画布不同。

父级移动带动全部后代；缩放父级只改变内容区，不缩放或自动重排子控件。子控件越界部分被裁切。调整父级尽量保持窗口内位置；新父内容区不足以容纳时拒绝整次命令。禁止自身或后代作为父级，禁止向叶子控件、锁定容器及不支持的布局挂接。单选按钮按父级分别互斥，改父引起的选中冲突在同一次命令中处理。

复制容器自动收集全部后代，保留局部坐标与内部顺序，重新生成对象标识、名称、代码名称及内部事件引用。引用到树外的连接不被复制。粘贴只平移根节点，子控件局部坐标不变。选中父子重叠集合时只操作最外层根，避免重复移动。删除整棵图元树前先解除待删除图元的父子所有权，避免撤销后访问已经被 Qt 释放的对象。

另有专项复现“移出子控件并删除旧容器”在分批构建中的生命周期故障：让出事件循环后，父级的延迟删除可能先于子级改父。构建器现在先把保留子树挂到保留根窗口，再删除旧父级，最后按新计划挂接。测试在每个构建步骤之间主动处理 Qt 延迟删除事件，验证子控件仍可访问且坐标正确；取消根替换时也会释放临时脱离父级的对象。

跨不同父级的集合暂不提供批量移动和排版；同级集合与整棵容器树已支持。对象树当前通过右键菜单调整父级，尚不支持直接拖动节点改父。

## 属性与事件规则

日期、时间、日期时间按固定格式存储，校验合法日期、闰年和范围。支持年份一七五二至九九九九，时间精确到秒，不接受时区后缀。日期时间以固定时区承载日历字段，避免宿主夏令时改写所显示的时分；本版不提供时区转换功能。

小数值必须有限，最多六位小数。缩小范围会联动调整当前值；降低小数位数时，范围、值和步长一并四舍五入，步长至少为当前精度的最小单位。数值框有明确上下限；液晶数字仅接入整数显示，显示位数不足时拒绝保存候选。

属性面板的日期输入提供中文下拉日历。保存回执等引起的面板刷新不会删除正在操作的日历编辑器。选择日期并离开编辑器或确认后提交，整次可撤销。

事件由注册表统一声明中文名和 Qt 信号，在原生构建检查中实际验证可连接。属性面板显示“事件”组，预览输出中文提示，不记录输入内容、日期或数值。可视化业务连接尚未实现；导出后仍通过 handlers.py 编写业务，不会把事件提示误当作业务代码生成。

## 运行与验证

在项目根目录执行：

```powershell
python -X utf8 main.py "examples/容器与日期示例.uipro"
python -X utf8 -m pytest -q
python -X utf8 -m tests.check_extended_widgets
python -X utf8 main.py --release-check reports/源码交付检查_0.6.0.json
python -X utf8 scripts/build_release.py
```

1. 从组件箱拖入分组框，再拖入按钮或日期编辑框，检查对象树中的父子关系。
2. 修改容器字体和内边距，移动容器，检查子控件位置；撤销后恢复。
3. 用“所属容器”属性或右键“移入容器”改变父级，检查超界调整与放不下时的中文提示。
4. 复制、粘贴、删除容器，检查后代完整，并逐次撤销和重做。
5. 在日期属性下拉日历中选择闰年日期；调整小数位数和范围，检查联动变化与撤销。
6. 保存后重新打开，按 F5 预览，导出独立项目运行，核对父级、坐标和属性。
7. 在“帮助 → 组件支持清单”搜索“定时器”或“小数位数”，确认支持状态和属性清单明确。

最终完整回归为 **496 项全部通过，耗时 74.44 秒**。其中扩展组件专项 41 项、容器专项 23 项，合计 64 项。专项覆盖全部新增类的枚举、无效日期、夏令时日期字段、小数舍入、复制保存往返、下拉日历刷新和隔离进程导出；容器专项覆盖嵌套坐标、裁切、层叠、祖先锁、改父、单选互斥、损坏剪贴板拒绝和分批删除生命周期。

真实桌面报告为 reports/扩展组件_桌面检查.json，截图为 reports/扩展组件_工作台.png、reports/扩展组件_预览.png、reports/扩展组件_日期属性.png 和 reports/扩展组件_支持清单.png。检查使用 Windows 平台插件和合成输入，不能代替物理鼠标、系统输入法、多屏及不同显示缩放验收。

本版还通过 tests.check_workbench 和 tests.check_multiselect 的原有真实桌面回归，覆盖紧凑窗口、属性焦点、文字撤销、边框选择、右键保留多选、整组复制删除与排版。源码交付报告 reports/源码交付检查_0.6.0.json 核验二十五类组件、三层控件树、保存加载、独立导出、容器坐标、闰年日期、小数精度及独立预览进程的启动停止。
