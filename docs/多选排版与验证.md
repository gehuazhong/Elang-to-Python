# 多选排版与验证

0.4.0 面向批量排版，补齐一次选中、移动、复制和删除多个控件的操作闭环。全部代码已落盘，可通过根目录 `main.py` 启动；无需迁移现有 `.uipro` 项目。

## 操作方式

| 操作 | 使用方法 |
| --- | --- |
| 追加或取消选中 | 画布中按住控制键或上档键单击控件 |
| 框选 | 从白色画布空白处拖动矩形，只选完全包含且在设计器中可见的控件；支持反向拖动 |
| 追加框选 | 按住控制键或上档键拖动框选 |
| 全选 | 画布或对象树获得焦点时按 `Ctrl+A`，选中设计器中可见的组件 |
| 对象树多选 | 控制键单击增减选择，上档键单击选择连续范围；与画布同步 |
| 整组移动 | 拖动任一已选控件；控件之间保持相对位置，整组吸附和约束边界 |
| 微调 | 方向键移动一像素，上档键加方向键移动十像素 |
| 取消手势 | `Esc`；窗口失焦、文档改变或选择改变时也取消临时手势 |
| 整组复制粘贴 | `Ctrl+C`、`Ctrl+V` 或右键；可跨文档粘贴，落点以整组左上角为准 |
| 批量删除 | `Delete` 或右键；包含锁定对象时全部拒绝 |
| 对齐 | “排版”菜单或右键子菜单；左、中、右、上、中、下六种方向，至少两个控件 |
| 等间距 | “水平等间距”“垂直等间距”，至少三个控件，保持首尾对象位置和全部尺寸 |

对齐基准为最后单击的控件；已多选时单击组内任一控件可把它设为基准，并保留整组选择。画布以较粗轮廓标记基准；右侧列出所选对象的位置、尺寸及基准名称，支持搜索这些对象。单独编辑属性时，单击组外对象，或通过控制键取消其他选择。

每次移动、排版、粘贴或删除都作为一个命令进入历史，`Ctrl+Z` 撤销整次操作，`Ctrl+Y` 重做。纯选择不修改项目、不增加历史、不导致已保存项目变为未保存。删除后撤销恢复控件数据，选择集不属于项目历史，不承诺同时恢复原多选范围。

输入框内的全选、复制、粘贴、删除、撤销仍由文字编辑器处理。多选界面不提供批量属性修改；右侧对象表是只读摘要，避免误以为修改会同时作用于整组。单选时原有八手柄缩放保持可用，多选不显示缩放手柄。

## 一致性与失败处理

`DocumentSession.selected_ids` 保存有序选择集，`selected_id` 保留当前基准与原有单选接口；二者只是会话状态，不增加 JSON 格式字段。画布手势只移动图元，提交前检查文档版本，释放鼠标后统一构造候选模型并验证，再写入历史。取消恢复所有原始位置。

批量移动与对齐要求同一父容器，无法自由定位或锁定的对象会阻止整次操作。移动使用整组公共偏移，不逐个限制坐标，因此贴近边界也不会挤乱间距。排版不进行二次网格吸附，以保证真实对齐；无法装入父容器时明确报错，不静默裁剪。等间距可用空间不足时拒绝操作；整数坐标导致的间隙误差最多一像素。

删除先一次遍历获取全部子树，校验锁定状态后再统一移除并重排对象顺序、层叠顺序；同时清除相关事件连接和焦点引用。对父子重叠选择不会重复删除，不逐个循环提交。

多控件剪贴板使用独立的第二版 MIME 数据，继续兼容第一版单控件数据。当前整组复制只支持同容器下无子控件、无布局的按钮、标签、单行编辑框，最多一千个组件、总数据一兆字节。未知属性、扩展和不支持的事件参数不会悄悄丢失。

整组复制保留内部信号连接、被引用的共享处理函数声明、对象顺序、层叠顺序和焦点顺序。粘贴时统一生成新标识并消除名称冲突，组内共享处理函数只复制一份，控件标识和处理函数标识分别映射。与组外对象的连接会跳过并显示中文计数提示；外部业务文件不进入剪贴板。

整组大于目标窗口时拒绝粘贴，避免扭曲相对位置。根窗口、工作区不能与普通组件混选；只读项目仍可选择和复制，不能移动、排版、删除或粘贴。右键菜单同时验证文档版本、选择集合和对齐基准，菜单打开后状态变化则拒绝旧操作。

本轮也修复了单控件剪贴板中控件标识与处理函数标识相同时的重映射错误，旧版数据协议保持不变。

## 当前边界

未实现整组缩放、批量属性写入、跨容器排版或复制、层级拖动、自动布局、可视化事件编辑和资源管理。设计器隐藏的控件不会被画布框选或全选，可通过对象树显式选择；运行时“可见”属性与设计器隐藏标志仍按原协议分别处理。

当前排版只覆盖已支持组件及自由定位容器。多屏、物理鼠标和输入法、长期使用与千控件连续手势性能仍需要独立验收，不能将模型测试当成完整交互性能承诺。

本版本仍为未签名开发预览包，对外商业发行的许可归属、干净系统与安装更新验证沿用上一版记录的待办。
