# 属性交互与稳定性审计

版本：0.7.4 开发预览版。日期：2026 年 11 月 7 日。

## 本轮目标

修复属性滚轮误操作，审查编辑、撤销、保存、预览及导出的完整流程，并通过长时间混合操作检查资源释放。保留现有架构与项目格式，不修改用户自己的工程或旧版便携包。

## 已复现并修复的问题

| 问题 | 复现条件 | 修复后的行为 |
| --- | --- | --- |
| 滚轮误改属性 | 鼠标位于尺寸、整数、小数、日期或普通下拉框上 | 有无焦点均不改变属性值；滚轮转交属性区，触控板位移与阶段保留；单次事件只滚动一次 |
| 工具栏意外缩放 | 滚轮经过缩放下拉框 | 不再自动改变查看比例；画布上的控制键加滚轮仍可缩放 |
| 下拉选择被中断 | 打开普通属性下拉框后收到后台刷新 | 保留正在操作的弹层，关闭后恢复刷新 |
| 步进输入丢失 | 按上下键或点击数值箭头后，尚未提交就收到刷新 | 单独记录待提交数值，提交、校验和撤销与手填输入保持一致 |
| 延后刷新未恢复 | 无实际变化的文本提交，或取消颜色选择 | 提交或取消完成后继续刷新，不再残留旧属性值 |
| 关闭时访问已销毁对象 | 面板排队刷新后，工作台先销毁 | 延迟回调绑定所属对象，销毁时取消回调 |
| 取消刷新后保留面板引用 | 原生对象先销毁，尚未执行的临时回调仍保留 Python 面板 | 面板使用可复用的所属定时器，其他短任务使用统一延迟调用；新增弱引用释放断言 |
| 对话框反复使用后累积 | 保存确认、恢复项目或“关于”结束，包含异常路径 | 读取返回结果后在清理分支释放对话框，不再一直保留到主窗口关闭 |
| 父级锁定状态不一致 | 选择锁定容器内的子控件 | 位置、尺寸及所属容器不可编辑，仍可编辑允许修改的文本等属性 |
| 保存后无法重新打开大项目 | 保存内容超过原有加载容量上限 | 写入前检查相同容量边界；超限时不写资源、不替换项目，也不修改备份 |
| 修复中的工具栏布局回归 | 将属性下拉框直接用于紧凑工具栏 | 工具栏使用独立尺寸策略，保持缩放入口可见；已有桌面检查抓到了此问题并完成复验 |
| 窗口跟随拉伸卡顿 | 大量组件开启跟随，每次鼠标移动都编译属性并重画整树，松手又还原和重画 | 临时计划复用已验证属性，仅更新变化的缓存；成功提交沿用画面，失败和取消恢复原状 |
| 高缩放启动越界 | 一千零八十行屏幕使用两倍缩放，可用逻辑高度只有五百一十六，原窗口最低高度六百二十 | 按可用屏幕调整最低尺寸和初始位置；新建工作台采用标签组件区并收起输出，不缩小字体 |

颜色窗口异常也有中文错误提示并保留原值。整数、小数和日期编辑器共用一致的边框、焦点和禁用样式。预览及导出控件的滚轮行为不受设计器属性保护影响。

## 实现边界

`panels/value_editors.py` 仅服务设计器。数值编辑器将滚轮转交最近的滚动区；通用选择器负责弹层生命周期和关闭状态的滚轮保护。`PropertyPanel` 仍通过文档命令提交，新增待提交数值和延后刷新状态，未绕过模型校验或撤销历史。

属性表和对象树持有可复用的单次定时器，直接刷新时也会停止已有排队任务；画布定位、编辑动作、关闭通知等短任务经 `core/deferred.py` 创建所属定时器。完成时释放定时器，所属对象先销毁时取消任务并释放回调引用。

本机 PySide6 6.11.1 的最小验证中，带上下文的临时回调在执行前被取消后，三十个已销毁原生对象的 Python 包装仍被保留；所属定时器方案的残留为零。因此最终实现没有继续使用该临时回调写法，也未通过周期性清缓存掩盖问题。普通方法和信号通知的执行、取消、引用释放都有回归用例。

窗口手势只从按下时的稳定构建计划计算新几何，复用相同的缩放算法和原属性对象；正式提交仍执行完整模型、注册表及命令校验。临时计划与完整编译结果在开关两种状态、容器自定义边距和六种边界尺寸下逐项比较。原生树区分属性继承变化与几何变化，页面和窗口条另外按真实像素尺寸检查缓存；父级字体变化仍会使后代缓存失效。

项目容量上限为 33,554,432 字节，按实际编码后的字节数检查。加载采用有上限的读取，摘要计算采用流式读取。超过上限的内存项目仍需精简内容后保存，本版没有新增大项目资源去重格式。

## 使用验证

1. 运行根目录 `main.py`，选中一个控件，把鼠标放在宽度、数值或下拉属性上滚动，确认属性不变而属性区正常滚动。
2. 展开字体或字号列表，用滚轮浏览，再单击选项；确认立即更新画布且可撤销。
3. 使用尺寸框的上下键和箭头修改数值，按回车提交，确认撤销一次恢复原尺寸。
4. 在窗口属性中开启“组件随窗口缩放”，拉伸设计窗口，再预览并拉伸运行窗口，确认组件位置与尺寸跟随且预览不回写项目。
5. 保存、关闭、重新打开项目，再导出并运行，确认属性及界面一致。

## 已知限制

验证覆盖本机 Windows、Python 3.11.8、PySide6 6.11.1，以及测试中明确列出的缩放倍率。物理滚轮、不同触控板驱动、中文输入法组合态、多屏动态切换和其他操作系统尚未完成实机矩阵验证。

通用可视化事件编辑、自动布局、对象树拖动改父、集中资源库及外部插件发现仍属后续功能。此版本继续标记为开发预览版，不宣称零缺陷或全部商业发行条件已经完成。

大量组件同时改变尺寸时仍需要重画原生控件，五百和一千控件场景的最慢帧尚未达到原架构目标。两倍缩放的本机屏幕可用逻辑范围为 960 × 516，已验证首次启动完整可达；这不代表所有编辑对话框、任意更小屏幕或动态跨屏缩放均已适配。
