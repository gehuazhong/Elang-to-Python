# 程序图标与验证

记录日期：2026 年 11 月 7 日。版本：0.7.5 开发预览版。

## 使用方法

点击工具栏“窗口属性”，在右侧“窗口”分组找到“程序图标”，点击“选择…”。也可在属性搜索框输入“图标”。

支持 ICO、PNG、JPG、JPEG、BMP、GIF、WEBP。选择后显示缩略图，画布标题栏立即更新；按 F5 可在运行窗口查看，代码导出后使用相同图标。“清除”恢复默认图标，选择和清除均作为一次文档操作支持撤销、重做。

无边框窗口保留图标设置，但没有可显示图标的系统标题栏。此属性设置运行窗口的图标；可执行文件的文件图标由打包配置决定。

## 保存与兼容

图标使用现有图片快照属性类型，稳定字段为 `window_icon`，默认值为空。多尺寸 ICO 选取像素面积最大的一帧，透明背景保留，再转换成静态 PNG 快照。动图使用首帧。

快照嵌入 `.uipro` 项目，保存、加载、恢复和撤销使用既有文档流程。删除或移动原图不会使项目丢失图标。旧项目缺少此字段时继续采用默认值，项目格式仍为第二版。

源文件最多十六兆字节，转换后的单张快照最多两兆字节；每边最多四千零九十六像素，总像素最多八百万。无效或超限文件会显示中文提示，保留原图标和撤销记录。

导出按属性元数据收集图片类资源，图标与图片框可以复用相同的摘要文件。快照写入当前生成版本的 `assets` 目录，运行时以模块位置解析相对路径；移动整个导出目录仍可使用。更新导出继续保留业务文件。

```powershell

python -X utf8 -m tests.check_window_icon
```

真实桌面检查已在 100%、150%、200% 启动缩放下通过，涵盖文件列表鼠标选择、属性行完整可见、标题栏即时更新、删除源文件后的保存加载与预览、独立导出及清除撤销。属性缩略图按设备像素比生成，避免高缩放下先缩小再放大。

报告为 `reports/程序图标_100_桌面检查.json`、`reports/程序图标_150_桌面检查.json`、`reports/程序图标_200_桌面检查.json`，同名前缀的截图记录文件选择器、工作台和运行窗口。
