# 画布交互优化与验证

记录日期：2026 年 11 月 7 日。

本次延续界面优化，补充第三阶段中的单对象缩放和键盘微调。其他第三阶段功能仍按原路线推进。

## 已完成行为

- 选中按钮或标签后，显示八个缩放手柄；手柄保持固定屏幕尺寸，画布放大或缩小时仍容易点击。小控件隐藏拥挤的边中点，保留角点。
- 主窗口使用右侧、底部和右下角手柄调整内容区尺寸；屏幕位置、子控件坐标不变。固定边框约束运行时大小，设计时仍可调整预设尺寸。
- 拖动期间显示位置和宽高，松开提交一次命令；退出键、切换对象、改变画布缩放、窗口失活、文档变为只读都会取消临时手势。
- 缩放按当前网格吸附，按住上档键可临时取消吸附。控件不能翻转，最小尺寸为一像素；正常位于内容区内的控件不能通过缩放拖出内容边界。
- 方向键移动选中控件一像素，按住上档键移动十像素；步长与画布缩放无关。属性输入框获得焦点时保留输入框自身的键盘行为。
- 属性面板将位置、宽高排列为两行，默认折叠“行为”和“高级”，保留中文搜索；代码名称移入“高级”。
- 精简工具栏占用，紧凑窗口仍可使用缩放选项。空窗口增加拖放提示，低缩放比例只显示较稀的主网格点，实际吸附间距不变。

## 实现边界

缩放中的变化只发生在设计图元：控件使用临时缓存缩放，窗口更新外框及内容区域。模型和原生控件保持提交前状态，松开后通过 `resize_node` 一次修改完整几何，并按最终尺寸重新生成原生外观。这样取消和撤销能够恢复同一份模型；拖动中的文字缓存可能暂时拉伸，松开后恢复正常字号。

根窗口尺寸允许小于原有子控件覆盖范围，超出内容区的部分暂时被裁切，子控件本身不会被删除或移动。设计器不把系统边框厚度写入内容尺寸。

本次仍是单选编辑，不包含多选缩放、框选、对齐辅助线、复制粘贴、事件编辑、代码生成和完整预览。

后续已交付当前组件范围内的独立窗口预览，操作方法与验证记录见 `预览功能与验证.md`。本文测试数量保留交互优化交付时的历史记录。

后续已补充按钮、标签的右键编辑及单对象复制粘贴，详见 `右键编辑与复制粘贴.md`。

## 运行与验收

```powershell
python main.py
python -X utf8 -m pytest -q
python -X utf8 -m tests.check_interactions
```

桌面检查只创建临时会话，不写入用户项目或个人布局。它会更新 `reports/交互优化_*.png` 和 `reports/交互优化_桌面检查.json`。

验证覆盖八个缩放方向与四档画布缩放、三种窗口边框、固定屏幕手柄尺寸、吸附及临时关闭吸附、单次提交、撤销重做、取消恢复、锁定及只读状态、拒绝提交后的恢复、键盘步长和几何属性搜索。

最终完整回归为 181 项通过，耗时 11.64 秒。本轮新增 53 项缩放回归及一项并排属性编辑回归；此前 127 项测试全部保留。

Windows 桌面检查已通过，设备像素比为 1.0。完整及紧凑窗口分别为 1280 × 820 和 960 × 620；合成鼠标将按钮从 160 × 40 调整为 208 × 64，原生控件、文档尺寸、属性面板和撤销保持一致。

检查使用真实 Qt 窗口与合成输入事件，未覆盖物理鼠标、跨显示器移动及操作系统缩放切换。
