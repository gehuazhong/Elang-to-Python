# 事件勾选与验证

记录日期：2026 年 11 月 7 日。版本：0.8.0 开发预览版。

## 使用方法

选择组件，在右侧属性面板展开“事件”。勾选后显示“已连接”，取消勾选显示“未连接”；新项目和原本没有事件连接的旧项目默认不连接。可在属性搜索框输入“事件”查看全部事件，或输入“被单击”“文本改变”等中文名筛选。

每次勾选作为一个文档操作提交，支持保存加载、撤销和重做。复制组件、容器或选择夹时保留内部事件设置，并重新生成连接和处理函数标识；时钟、通用对话框及窗口条也适用。取消勾选保留处理函数身份，重新勾选继续使用原来的业务入口。

按 F5 使用当前勾选状态创建独立预览。已打开的预览采用启动时的快照，修改勾选后再次按 F5 更新。预览只报告勾选事件的名称，不执行导出目录中的业务文件，也不输出输入内容。未勾选不会关闭控件本身的输入、选择、绘画等原生行为。时钟、鼠标移动和重绘等高频提示会合并，事件本身不按日志频率丢弃。

## 事件范围

已核对三十三类组件，以及窗口、工作区和选择夹页面，共三十六个注册组件。原生信号逐项与当前真实 Qt 元对象比对，并实际连接验证。选择框统一使用新版 `checkStateChanged`；弃用的整数别名 `stateChanged` 不重复列出。

可视组件补充二十五种常用 Qt 事件，涵盖鼠标按下、放开、双击、移动、进入、离开、滚轮，键盘按下、放开，焦点进入、离开，显示、隐藏、尺寸、位置、关闭、窗口激活与失活，以及快捷菜单、重绘、输入法和拖放。时钟和通用对话框只提供适用的对象及专用信号。

列表、表格、树形和多行编辑框的鼠标事件转接到实际内容视口；数值和可编辑组合框处理内部编辑框；选择夹转接页签，工具条和编辑框转接内部按钮。专用信号继续传递 Qt 原始参数，包括按钮勾选状态、文本、索引、表项、日期等。

每个组件的中文事件、稳定字段及 Qt 来源见 `组件支持矩阵.md`，也可通过“帮助 → 组件支持清单”搜索。这里只覆盖已接入组件的公开信号及列出的常用 Qt 事件，不包括尚未接入的组件或 Qt 内部所有事件类型。

## 导出业务代码

导出 Python 项目后，勾选事件自动连接到 `event_handlers` 中的对应 Python 函数。例如按钮的“被单击”通常生成 `event_handlers/on_button_1_clicked.py`：

```python
def on_button_1_clicked(window, *arguments):
    checked = arguments[0]
    window.setWindowTitle("已选中" if checked else "未选中")
```

第一个参数 `window` 是窗口，通过 `window.controls["代码名称"]` 获取组件。信号参数按 Qt 原始顺序传递；鼠标、键盘、关闭等通用事件传入一个 Qt 事件对象，只在当前同步调用中使用。默认保留 Qt 原生处理；函数返回 `True` 可阻止默认处理。取消窗口关闭需对事件调用 `ignore()` 并返回 `True`；接受自定义拖放需在拖动进入事件调用 `acceptProposedAction()` 并返回 `True`。

重复导出只新增缺失的函数文件，已有 `event_handlers` 文件和 `handlers.py` 保留。取消勾选后不导入、不自动连接该事件的业务文件，也不删除文件。根目录 `handlers.py` 仍提供窗口初始化和手动连接入口。请避免把已自动连接的事件再手工连接一次。

生成界面使用不可变版本目录和原子指针发布。勾选事件的业务文件存在语法错误、缺失对应函数或在导出过程中被修改时，不切换当前版本。旧项目中的标准槽连接和常量、事件参数映射继续支持；未知事件及不适用的目标操作会明确报错。
