# 字体字号选择与验证

本轮版本为 0.7.2，将窗口与组件的“字体”和“字号”属性改为不可手填的下拉选择器。运行依赖、模型格式和生成代码格式沿用现有实现。

## 操作

选中组件，在属性面板的“外观”中点击“字体”，从已安装字库选择。中文名称在前，其次是支持简体中文的字体，后面保留其他字体。字体名称来自系统，选项使用对应字形显示；系统提供的英文字体名称不擅自翻译，以免改变实际引用。弹层约十二行，更多字体通过滚动选择。

“字号”列出常用值，其余整数值位于分隔线之后，范围为一至九十六磅。无需记住或键入数值。当前格式只支持整数磅，因此不提供需要半磅精度的中文字号别名。

字体与字号均有“继承默认”选项，分别保存为空字符串和零，继续跟随所属容器或系统。选择即应用，每项修改各产生一次可撤销操作。取消弹层不改项目；属性表滚动经过关闭的选择框不会误改字体。

已保存的非热门字号仍可正确选中。若原字体本机没有，显示“本机未找到”，保留字体名；系统仅在显示时使用回退字体。打开项目、刷新属性和保存均不会擅自替换，只有用户重新选择才修改。

## 文件与验证

| 文件 | 作用 |
| --- | --- |
| panels/font_editor.py | 本机字体、字形展示、字号列表、默认继承和弹层生命周期 |
| panels/properties.py | 接入选择器，并在弹层展开期间延后刷新 |
| tests/test_font_editor.py | 鼠标选择、取消、继承、撤销重做、缺失字体、保存预览与导出一致性 |
| tests/check_font_editor.py | 真实桌面字库、鼠标操作、弹层行数和截图检查 |
| app/release_check.py | 在源码和便携包内验证字体与字号选择器及撤销 |
| app/version.py、pyproject.toml、release/version_info.txt | 同步版本 |
| README.md、release/使用说明.txt | 操作说明 |

```powershell
python -X utf8 main.py
python -X utf8 -m pytest -q tests/test_font_editor.py
python -X utf8 -m pytest -q
python -X utf8 -m tests.check_font_editor
```

Windows 离屏 Qt 插件可能不枚举系统字库，因此专项测试在需要时显式加载本机字体文件，结束后移除测试注册，不更改系统安装。真实桌面检查直接枚举系统字体；截图是实际控件或弹层的 Qt 绘制结果。

不嵌入或打包用户选择的字体文件。目标电脑未安装字体时仍由系统回退；这是字体分发范围，与保存的字体名称无关。设备像素比启动检查不等同于多屏移动或系统显示设置切换测试。
