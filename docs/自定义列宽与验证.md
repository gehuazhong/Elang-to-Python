# 自定义列宽与验证

版本：0.8.1 开发预览版。记录日期：2026 年 11 月 7 日。

## 操作

选择表格后打开“内容 → 表格内容 → 编辑…”，或选择超级列表框后打开“内容 → 表项与列 → 编辑…”。窗口下方新增“当前列”和“列宽”。

可单击列标题、单元格，或使用“当前列”选择器定位列，再输入宽度。例如 ID 列为 56、名称列为 160、详细说明列为 280。也可拖动列标题右边界调宽，输入框会同步显示结果。

“适应内容”根据编辑窗口中的列标题和单元格文字计算宽度。“恢复默认”清除当前列的自定义宽度，使其跟随组件“默认列宽”。宽度范围为一到二千个逻辑像素；零表示默认。空表没有数据行时，同样可以配置和删除列。

点击“确定”后，列标题、行数据和各列宽度作为一个操作提交；“取消”不修改项目。增加列使用默认宽度，删除列同时移除对应宽度。修改文字、移动数据行不会改变其他列宽度。

## 显示与保存

画布、预览和导出程序复用相同的列宽适配。宽度随项目保存和组件复制，并支持撤销重做。旧项目没有各列宽度时保持原默认规则：表格默认为 100，超级列表框沿用其“默认列宽”属性。

自定义宽度优先于“默认列宽”。末列已有自定义宽度时，“末列填满”不会覆盖它；需要自动填满剩余空间时，将末列恢复默认并开启“末列填满”。组件变窄时保留明确列宽，通过横向滚动查看内容。

字段 `table_data.column_widths` 为与列标题数量一致的整数数组，零代表默认。旧项目无需迁移，无需增加新的顶层格式版本；不合法的数量、类型或范围会在提交前拒绝。运行中的临时拖动和业务代码改宽不会回写设计项目。

本功能适用于当前支持多列表项数据的表格和超级列表框。普通列表框仍使用单列项目，树形框仍使用现有单列节点结构。

## 验证

专项测试见 `tests/test_column_widths.py`，覆盖各列宽度保存、复制、撤销、画布缓存、预览、独立导出、默认宽度和末列填满、非法数据、旧项目、空表、拖动调宽、适应内容、取消草稿及单次提交。

真实 Windows 桌面在 100%、150%、200% 启动缩放下使用相同的 56、160、280 逻辑像素宽度，检查数字输入、列标题拖动、窗口与输入控件完整可见，以及保存加载、预览和导出的一致性。截图和 JSON 报告保存在 `reports/自定义列宽_*`。

交付检查增加“逐列宽度编辑画布与撤销”和“逐列宽度保存加载与导出”，源码与便携包使用同一检查流程。桌面操作使用 Qt 合成输入，未覆盖物理鼠标及跨屏动态缩放。
