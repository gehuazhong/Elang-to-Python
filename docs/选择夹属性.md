# 选择夹表头与页面

选中“选择夹”本身，在属性面板的“表头”分组设置页签栏；选中具体页面则可修改页标题、页签图标及提示文本。

| 分组 | 属性 | 行为 |
| --- | --- | --- |
| 表头 | 表头朝向 | 顶部、底部、左侧、右侧；左右朝向旋转文字 |
| 表头 | 显示表头 | 关闭后释放表头空间，仍可通过对象树、当前页或代码切换页面 |
| 表头 | 单页自动隐藏表头 | 只有一个页面时自动隐藏，新增页面后恢复 |
| 表头 | 表头厚度 | 上下表头的高度，或左右表头的宽度；默认 30 逻辑像素 |
| 表头 | 页签形状 | 圆角或三角 |
| 表头 | 页签均分表头 | 打开后让页签均分可用长度 |
| 表头 | 显示页签滚动按钮 | 页签过多时显示滚动箭头 |
| 表头 | 长标题省略方式 | 不省略、省略开头、中间或末尾 |
| 表头 | 文档模式、绘制表头基线 | 调整原生 Qt 页签的文档式外观及底线 |
| 表头 | 页签图标宽度、高度 | 控制各页图标显示尺寸 |
| 外观 | 显示页面边框 | 与表头独立控制；两者均关闭时内容填满容器 |
| 行为 | 允许拖动页签排序 | 预览和导出程序中，页签与页面内容一起移动 |
| 行为 | 显示页签关闭按钮 | 点击触发“页签关闭请求”，由业务代码决定如何处理 |

共新增 15 个选择夹属性和 1 个页面图标属性，保留原有“当前页”。旧项目未填写新增属性时使用兼容默认值：顶部表头、厚度 30、显示表头和页面边框。

切换表头方向、显示状态和厚度后，画布内容范围、点击切页、嵌套位置、窗口跟随缩放和独立导出使用相同的几何规则。属性修改、页面增删支持撤销。

“页签关闭请求”对应 `tabCloseRequested(index)`，只发出请求，不自动删除页面或其内容。“页签顺序改变”对应 `tabMoved(from_index, to_index)`。拖动排序只影响本次运行；设计顺序在对象树中调整。各页的“提示文本”同时用于表头悬停提示。

隐藏表头后，运行代码可通过 `window.controls["选择夹代码名称"].set_current_page(index)` 切换页面，索引从零开始。设计器中可通过“页面 → 当前页”或对象树切换。

对照示例：[选择夹表头与页面](../examples/选择夹表头与页面.uipro)。包含四种朝向以及隐藏表头、关闭边框的示例。

```powershell
python -X utf8 main.py examples/选择夹表头与页面.uipro
python -X utf8 -m pytest tests/test_selection_tabs.py -q
python -X utf8 scripts/check_selection_tabs.py
```

原生窗口、设计器截图和独立导出检查报告位于 `reports/selection-tabs`。源码更新后需重新启动设计器；已有独立导出需重新导出以包含新适配器。历史便携包未重打包。
