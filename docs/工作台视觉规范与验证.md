# 工作台视觉规范与验证

记录日期：2026 年 11 月 7 日。

本次改版将设计器调整为紧凑的桌面工作台。重点是阅读、定位与编辑效率，沿用现有 PySide6 结构和中文操作，不添加第三方依赖。

## 本次调整

原界面的淡蓝色覆盖了标题、文字、边框、面板和选中状态；大量圆角输入框与较宽留白增加了视觉重复。本次以中性灰组织面板和画布，用深色文字、分隔线和少量灰绿色区分状态。

- 工具栏移除重复的品牌标题，缩小按钮内边距与分隔间距；保留中文操作名称和预览、停止、缩放入口。
- 组件箱采用紧凑列表，提示缩为一行；对象树固定类型列宽，把其余空间交给对象名称。
- 属性面板采用连续表格。编辑框平时融入单元格，悬停和键盘焦点时显示边界；搜索、枚举、颜色、复选框及禁用状态保持可辨。
- 减少面板标题、标签页和画布信息条的高度；日志改用对比更清楚的正文颜色。
- 设计窗口改为细边框和轻微投影，网格使用中性灰。选框、拖放轮廓、缩放手柄与焦点使用同一强调色。
- 控件缓存启用平滑缩放，改善小比例查看时中文笔画被截断的现象。百分之一百查看仍保留原生尺寸。

## 后续视觉约定

| 项目 | 约定 |
| --- | --- |
| 字体 | 延续当前中文界面字体及十磅基线，不通过大标题挤占编辑区 |
| 表面 | 面板浅灰，编辑表格接近白色，画布使用较深中性灰 |
| 文字 | 正文深灰，辅助说明使用较浅灰色；禁用状态独立处理 |
| 强调色 | 灰绿色用于焦点、选择、运行与开关状态，避免铺满全部面板 |
| 边框 | 一像素分隔为主，外部输入框使用小圆角，属性单元格保持直角 |
| 图标 | 延续项目自绘线条图标，统一笔画与中性颜色，不引入另一套图标库 |
| 信息密度 | 控件行保持可点击；菜单、工具栏、组件箱与属性表按各自任务调整间距 |
| 交互状态 | 输入焦点、悬停、按下、选中、禁用必须能区分；复选框未选中时也保留轮廓 |
| 提示 | 使用具体操作说明，避免重复标题、大段引导或与任务无关的装饰 |

设计器外壳的调色板只设置在设计器主窗口，不改写应用默认调色板。被设计控件继续使用运行时构建器和项目属性，独立预览不继承外壳样式。用户已保存的面板布局继续使用，不为改版清空个人设置。

## 验证方式

在项目根目录执行：

```powershell
python -X utf8 main.py
python -X utf8 -m pytest -q
python -X utf8 -m tests.check_workbench
python -X utf8 -m tests.check_interactions
python -X utf8 -m tests.check_preview
python -X utf8 -m tests.benchmark_canvas
```

最终完整回归为 213 项通过，耗时 19.76 秒。实际 Windows 桌面检查覆盖属性焦点、回车提交、单次撤销、边框下拉键盘选择、固定边框禁用状态、缩放手柄、紧凑布局及样式隔离；独立预览的原生交互与停止检查通过。

实机设备像素比为 1.0，检查窗口为 1280 × 820 和 960 × 620。紧凑窗口中工具栏高度为 43 个逻辑像素，预览与缩放入口保持可见。截图保存在：

- `reports/工作台_主窗口.png`
- `reports/工作台_窗口属性.png`
- `reports/工作台_属性输入.png`
- `reports/工作台_紧凑布局.png`

检查结果见 `reports/工作台_桌面检查.json`。脚本仅建立临时文档并生成报告，不保存用户项目或覆盖个人布局。

平滑缩放启用后的既有画布基准结果如下，单位为毫秒：

| 控件数量 | 连续手势第九十五百分位 | 提交至稳定画面 | 最大构建批次 |
| --- | --- | --- | --- |
| 100 | 1.870 | 9.633 | 6.059 |
| 500 | 4.223 | 40.553 | 7.517 |
| 1000 | 5.164 | 84.897 | 6.851 |

原始报告在 `reports/第二阶段画布基准.json`。测试仍使用原有独立进程、五帧预热、六十个正式样本和实际视口绘制；连续手势指标处于原定门槛以内。该基准不计操作系统显示合成或物理鼠标延迟，也不是与旧版同机并发对照的性能比较。

## 已知边界

小比例查看仍受屏幕像素数量限制，需要精读控件文字时可切回百分之一百。操作系统非客户区、物理输入、跨屏及系统显示缩放切换没有在本轮验收中覆盖。

本次调整视觉与编辑反馈，组件种类、事件执行和代码生成能力以现有阶段说明为准。截图内的“界面设置”是检查脚本创建的示例设计，不表示应用新增了设置业务逻辑。
