# 全量审计与修复（2026-11-10）

这轮结合代码检查、故障复现、完整测试、混合编辑压力和 Windows 实机验证，检查近期属性补全与工作台设置，以及原有保存、撤销、预览和导出流程。

## 已复现并修复

| 问题 | 触发方式和影响 | 修复 |
| --- | --- | --- |
| 损坏配置阻止启动 | 窗口位置或布局配置变为文本、数字或列表时，直接传给 Qt 恢复函数会抛出类型异常，主窗口无法完成初始化 | 恢复前验证二进制数据类型；无效配置使用默认布局，保留正常偏好 |
| 外观修改重建模型 | 修改列表、表格、树和分栏模型视图的颜色等属性，也会重新创建数据模型，丢失当前选择和运行时编辑状态 | 根据实际内容判断是否重建，外观和列宽变化复用原模型及选择状态，减少 Qt 对象创建 |
| 分栏视图积累旧选择模型 | 每次替换内容都会额外保留一个视图所有的旧选择模型；复现中 12 次替换后从 1 个增加到 13 个 | 替换时释放由当前视图持有的旧选择模型，不释放外部所有的对象 |
| 属性列宽重启丢失 | 拖动属性名列宽后，重启恢复为 110；已保存的大字号首次应用也没有缩放列宽 | 保存和校验属性列宽，首次启动按字号缩放；恢复默认回到初始列宽，取消仍还原原宽度 |

回归测试为 `tests/test_full_audit.py`，修复前记录在 `reports/full-audit-20261110/reproduced.xml`。失败用例保留并用于后续回归，没有跳过断言。
