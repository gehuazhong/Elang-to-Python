# 组件补全与验证

版本：0.10.0。组件箱由 33 类扩展到 37 类；包含主窗口、工作区、选择夹页面、菜单栏、菜单项共 42 个注册类型。这里的“接入”指本项目列出的能力，不表示 Qt 的所有组件或所有属性都已实现。

## 新组件

| 组件 | 中文属性 | 主要事件 |
| --- | --- | --- |
| 富文本编辑框 | 纯文本/HTML 内容、只读、占位文字、换行、制表符宽度、光标宽度、文档边距、富文本粘贴、撤销 | 文本、选区、光标、字符格式、可复制/撤销/重做状态改变 |
| 文本浏览器 | 富文本编辑框属性，以及自动跟随链接、使用外部程序打开链接 | 链接点击/悬停、页面来源、历史、可前进/后退状态改变 |
| 字体组合框 | 当前字体、全部/等宽/比例/可缩放/点阵字体范围、文字系统、允许输入、下拉显示项数 | 字体改变、选项确认、高亮、当前文本和索引改变 |
| 快捷键编辑框 | 当前单组快捷键、清除按钮 | 快捷键改变、编辑完成，以及鼠标/键盘/焦点事件 |

四类组件具备中文属性编辑、保存加载、复制、撤销、原生画布绘制、独立进程预览及 Python 导出。事件仍默认不勾选，只有勾选项连接处理函数。字体来自运行机器，项目不打包字体；富文本使用 Qt 支持的 HTML，不是网页浏览器。

快捷键编辑框只负责录入。业务代码可以将 keySequence() 应用到按钮或菜单，示例展示了这一过程。预览中录入 Esc 时不会退出；Shift+F5 保留为停止预览操作。

## 原有组件补全

- 按钮、工具按钮、命令链接按钮、选择框、单选框：图标、图标宽高、显式快捷键；补齐重复触发及延时、间隔。图标宽高为零保持 Qt 原生尺寸，清除图标后恢复默认图标。
- 菜单项：图标和提示文本；图标资源随项目保存及导出。
- 标签：纯文本/富文本、文本选择、链接点击和外部链接开关。已有纯文本项目继续使用纯文本。
- 分组框：显示选择框、已选中。子控件属性应用完成后再应用组状态；未选中组禁用后代，重新选中保留子控件自身的禁用设置。
- 整数、小数、日期时间：输入时实时更新、显示边框、长按加速；补充调节按钮样式，小数框支持最小值替代文字。
- 滑块、旋钮、滚动条：反向操作，默认值保持各自原生行为。
- 多行编辑框：制表符宽度、光标宽度、滚动时居中光标。

按钮与菜单的显式快捷键统一检查重复。粘贴时保留目标窗口已有快捷键，只清除新副本中冲突的值，状态栏显示清除数量；无冲突的跨项目粘贴保留设置。快捷键录入内容不参加执行快捷键冲突检查。

## 修复与回归重点

1. 标签原来被强制设置为纯文本，虽然列出了链接事件，却不能设计可点击的 HTML 链接。增加明确的格式与交互属性，并通过真实鼠标点击验证。
2. 字体组合框继承普通组合框，不能沿用清空后填入项目列表的适配，否则会清掉系统字体。普通项目列表适配仅在声明 items 属性时运行。
3. 快捷键编辑框的文本由内部编辑框绘制，画布必须绘制内部子控件；键盘事件则由外层组件接收，分别正确处理。
4. 新增按钮快捷键后，直接复制会与原控件冲突而阻止粘贴。单控件、多选、容器整树三条粘贴路径统一处理冲突，并覆盖撤销与重做。
5. 可勾选分组框的父子属性顺序、原先禁用的子控件、嵌套组以及从未选中组移出子控件均有回归。
6. 画布、预览协议和导出共用组件挂接位置清单。全注册目录通过真正的 PreviewService 子进程启动与停止，防止重复出现“只有菜单却提示不支持组件”的入口遗漏。
7. Windows 的剪贴板通知可能延后，复制后立即刷新粘贴动作，避免快速 Ctrl+C、Ctrl+V 时不生效；用阻断通知的测试验证不依赖通知时序。
8. 字体列表中的空名称不再重复显示为默认选项。未知组件版本的快捷键数据继续原样保留，避免新校验阻止兼容打开。

## 示例与检查

第六份示例位于 uidemo/06_文本与输入组件，可在设计器继续编辑，也可运行独立 Python 导出。业务包含富文本同步预览、字体字号、分组只读、图标按钮、快捷键重绑定、标签链接与正文恢复。

专项测试覆盖 tests/test_input_extras.py、tests/test_shortcut_copy.py、tests/test_preview_interactions.py；tests/test_events.py 对照真实 Qt 元对象检查所有已注册组件的信号。源码与便携包共用 app/release_check.py，检查保存加载、图标、富文本、字体、快捷键、分组、代码导出、普通预览及仅菜单项目预览。

完整能力清单由注册表生成，见 [组件支持矩阵](组件支持矩阵.md)。自动布局、滚动容器、集中资源库、内置业务代码编辑器和其他尚未接入组件仍按清单标记。
