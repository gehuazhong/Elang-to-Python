# 预览功能与验证

记录日期：2026 年 11 月 7 日。

本次交付当前组件范围内的独立窗口预览。复用既有构建计划和运行时属性适配，不增加第三方依赖，不改变项目格式。

## 操作方法

1. 使用 `python main.py` 启动设计器，拖入按钮或标签，编辑窗口标题、尺寸、边框及控件属性。
2. 点击工具栏“预览”、菜单“运行 → 预览”，或在设计器内按 `F5`。未保存的项目也能预览；属性输入框中尚未失去焦点的文字会先提交，校验失败时保留输入并显示提示。
3. 预览窗口中的按钮可以真实点击；开启“可选中”后可以切换选中状态，底部输出显示中文事件反馈。运行期间产生的交互状态不会回写设计文档，也不会增加撤销记录。
4. 修改设计后返回设计器，点击“重新预览”或按 `F5`。旧预览关闭后启动新快照，连续操作仅保留最后一次请求。
5. 通过预览窗口关闭按钮、`Esc` 或 `Shift+F5` 关闭预览；也可在设计器中点击停止图标或使用“运行 → 停止预览”。无边框、关闭按钮禁用或整窗禁用时，设计器的停止入口仍可用。
6. 切换文档标签不会关闭原预览；关闭预览所对应的设计文档或退出设计器时，会一并停止其预览进程。

当前同一设计器实例只运行一个预览。修改设计后需要重新预览，不会自动刷新已经打开的窗口。

## 实现方式

设计器先验证不可变文档快照，经标准输入发送版本化 JSON 消息；子进程用当前 Python 解释器启动，从同一控件注册表编译构建计划，再以运行模式创建真实 Qt 窗口。控件创建和属性写入始终在各自进程的界面线程执行。

消息包含任务标识、文档状态标识和注册表指纹。预览使用独立进程，避免其窗口异常直接破坏设计器；这不构成插件代码的安全沙箱。预览过程不生成 Python 文件，不保存项目文件，只记录诊断日志。

启动超时默认十五秒；停止请求先正常关闭，超过一点五秒仍未响应才强制结束本服务创建的预览进程。子进程结束时发送通知，父进程关闭输入管道；读取线程使用无缓冲管道并参与退出清理。父进程退出导致管道结束时，预览也会关闭。

预览沿用现有标题、内容区尺寸、标准／固定／无边框、窗口按钮、置顶、颜色、字体、可见、启用、层级与焦点顺序。设计器专用的隐藏标记不会代替运行时“可见”属性。主窗口不可见时拒绝预览并显示中文原因；完全落在所有屏幕之外的位置仅在预览中调整，不修改项目。

底部输出显示中文状态和错误摘要。详细诊断写入本应用本地数据目录下的“日志/设计器.log”和“日志/预览.log”；原始 Qt 诊断不直接显示在中文输出面板。

## 修改文件

| 文件 | 职责 |
| --- | --- |
| `preview/__init__.py`、`preview/protocol.py` | 预览包、版本化消息、大小限制、快照预检 |
| `preview/service.py` | 独立进程、状态切换、重启、超时、输出及会话退出 |
| `preview/worker.py` | 子进程入口、管道读取、主线程构建与退出握手 |
| `runtime/preview.py` | 真实控件交互、中文事件反馈、焦点顺序和关闭快捷键 |

| `resources/icons.py` | 预览和停止图标 |
| `panels/output.py` | 区分中文摘要与仅供诊断的日志 |
| `tests/test_preview.py` | 协议、运行窗口、真实子进程与设计器集成回归 |
| `tests/preview_probe.py` | 复用正式子进程逻辑的测试入口，自动点击、关闭及截图 |
| `tests/check_preview.py` | Windows 桌面检查与报告生成 |
| `README.md`、本说明及相关阶段文档 | 当前能力、操作方法及验证边界 |

实现代码完整保存在上述文件中，正式预览入口不包含测试专用的自动点击与截图操作。

## 运行与验证

在项目根目录执行：

```powershell
python -X utf8 main.py
python -X utf8 -m pytest tests/test_preview.py -q
python -X utf8 -m pytest -q
python -X utf8 -m tests.check_preview
python -X utf8 main.py --smoke-test
```

预览专项共 32 项通过，耗时 8.52 秒；完整回归共 213 项通过，耗时 19.36 秒，包含此前 181 项。启动检查通过。验证使用 Python 3.11.8、PySide6 6.11.1 和 pytest 8.3.4。

专项覆盖真实控件点击、禁用控件、可见性、字体颜色、三种边框、焦点顺序、关闭及重复释放、未保存文字提交、重新预览采用最新快照、启动期间停止、解释器启动失败、启动超时、异常退出及重启、父管道断开、分段中文消息、非法协议、多文档归属与设计器退出。直接关闭预览和使用退出键的独立进程检查均正常结束，不依赖强制终止。

Windows 桌面检查通过，设备像素比为 1.0。真实独立预览的内容区为 640 × 420，按钮合成点击后中文日志收到“被单击；已选中”，文档字节、状态标识及撤销游标保持不变。960 × 620 的设计器窗口仍完整显示预览、停止、适合窗口及缩放入口。

检查脚本只创建临时会话，不改写用户项目或个人布局；截图和检查结果写入：

- `reports/预览_运行窗口.png`
- `reports/预览_设计器.png`
- `reports/预览_紧凑布局.png`
- `reports/预览_桌面检查.json`

运行窗口截图由 Qt 抓取内容区，不包含操作系统标题栏和外框。桌面检查使用合成输入，尚未覆盖物理鼠标、跨显示器操作或操作系统缩放切换。

## 已知限制

当前支持已实现的窗口、工作区、按钮和标签。未知组件或尚未支持的挂接类型会拒绝预览，不会静默遗漏。新快照预检失败时，已经运行的旧预览保持可用。

按钮的中文事件日志仅是原生交互反馈。项目中保存的自定义连接和处理函数尚未执行，存在这些数据时会明确提示。资源清单保留，但当前控件尚无图片资源适配。代码生成、完整组件库、资源管理及插件加载仍按后续阶段实现，不能将本次预览验收视为这些功能已经完成。

本次验证基于源码环境启动子进程，尚未覆盖打包为独立可执行文件后的入口安排。系统边框细节及置顶表现依赖操作系统；跨平台外观与生成代码的一致性需要在对应功能实现后单独验证。
