# 单行编辑框与验证

## 本轮目标

新增基于 `QLineEdit` 的单行编辑框，沿用组件注册、不可变模型、命令历史和统一运行构建器。组件位于左侧“输入组件”分组，可搜索“编辑框”，拖入画布或双击创建。

初始内容为空，占位文本为“请输入内容”，默认尺寸为 200 × 32。按钮和标签仍以对象名称初始化文字；该差异由注册元数据的 `text_from_name` 配置，不再把所有含文本属性的组件都填入对象名称。

## 中文属性

| 分组 | 属性 | 行为 |
| --- | --- | --- |
| 基本 | 名称、文本、占位文本 | 文本为空时显示占位提示；名称用于对象树和预览事件提示 |
| 位置与尺寸 | 位置X、位置Y、宽度、高度 | 支持属性编辑、拖动、缩放手柄、微调和撤销重做 |
| 外观 | 显示边框、对齐方式 | 边框可开关；支持靠左、居中、靠右 |
| 外观 | 背景色、文字颜色、字体、字号 | 复用现有外观适配，画布与预览共用属性应用规则 |
| 行为 | 最大长度 | 范围为 0 到 32767，默认 32767；按 Qt 使用的十六位文本编码单元计数，部分字符占两位 |
| 行为 | 只读 | 只读时预览不能输入；设计时仍可通过属性面板修改初始文本 |
| 行为 | 显示方式 | 正常显示、密码显示、不显示内容、编辑时显示密码 |
| 行为 | 清除按钮 | 默认开启；运行时有可编辑内容时可单击清除 |
| 行为 | 启用、可见、提示文本 | 提示文本是鼠标悬停说明，与占位文本分别设置 |

输入的初始文本不能包含换行，也不能超过最大长度。缩短最大长度但现有文本过长时，提交会被拒绝并显示中文提示，避免原生控件截断文字后与项目内容不一致。要降低限制，请先缩短文本。

显示方式仅控制显示，项目 JSON 仍保存所配置的初始文本，不提供密码加密存储。

## 编辑与预览

1. 执行 `python -X utf8 main.py`，在组件箱展开“输入组件”，拖入“单行编辑框”。
2. 通过右侧属性设置文本、占位文本等；回车或离开输入框后应用。
3. 在画布中选中、拖动或拉伸编辑框；右键可复制、粘贴和删除，支持原有快捷键与撤销重做。
4. 保存为 `.uipro` 后重新打开，编辑框及其属性会完整还原。
5. 按 `F5` 运行预览，在预览窗口中输入中文、使用清除按钮或按回车。

设计画布中的编辑框保持设计选择行为，不接管键盘输入。预览中可以输入，运行时输入不会回写设计文档，也不会产生设计撤销记录。

预览输出支持“文本改变”“按下回车”“编辑完成”提示，分别连接真实的 `textChanged`、`returnPressed`、`editingFinished` 信号。提示只记录对象名称和事件名称，不记录用户输入内容。完整事件编辑和业务处理函数执行仍待后续阶段实现。

画布绘制包含编辑框内部清除按钮，并在抓取静态缓存前完成内部动画，避免缓存到按钮淡入时的透明首帧。该处理仅用于设计缓存，不修改运行预览的动画行为。

## 修改文件

| 文件 | 修改内容 |
| --- | --- |
| `widgets/builtin.py` | 注册单行编辑框及中文属性 |
| `core/metadata.py`、`core/commands/nodes.py` | 由元数据控制是否把对象名称作为初始文字 |
| `core/registry.py`、`core/validation.py` | 校验单行文本长度、换行限制及非容器身份 |
| `core/commands/clipboard.py` | 允许复制、校验、还原编辑框片段 |
| `runtime/builder.py` | 接入真实控件工厂、显示方式枚举和内部清除按钮缓存 |
| `runtime/preview.py` | 原生编辑信号的中文预览提示 |
| `resources/icons.py`、`panels/toolbox.py` | 编辑框专用图标及组件箱图标映射 |
| `panels/properties.py`、`panels/object_tree.py` | 新属性说明及对象类型完整悬停提示 |
| `app/main_window.py` | 更新当前组件范围的界面说明 |
| `tests/test_line_edit.py` | 22 项专项回归 |
| `tests/line_edit_probe.py`、`tests/check_line_edit.py` | 独立子进程输入探针及真实桌面检查 |
| `README.md`、本文 | 更新使用说明与验证结果 |

代码已直接写入上述文件，新增组件不需要额外依赖，也不改变 `.uipro` 的结构版本。新类型标识为 `builtin.line_edit`，现有按钮和标签项目继续可加载。

## 当前限制

本轮实现单行编辑框。多行编辑框、输入掩码、正则验证器、完整事件编辑和代码生成尚未实现。

中文输入通过合成的输入法提交事件验证，尚未验证真实输入法候选窗口和组合态交互，也未覆盖物理输入与跨屏显示缩放。旧版本设计器没有新组件适配器，需要使用更新后的程序进行完整编辑和预览。
