# VS Code 风格界面

设计器工作台使用深色编辑器视觉，包含以下层次：

| 区域 | 背景 | 说明 |
| --- | --- | --- |
| 菜单和工具栏 | `#181818` | 与侧栏以细边界分隔 |
| 组件箱、对象树、属性区 | `#252526` | 使用 VS Code 侧栏层级 |
| 画布工作区 | `#1e1e1e` | 设计窗口保持项目自身颜色 |
| 选中态 | `#094771` | 用于对象树、列表和菜单 |
| 焦点边框 | `#007fd4` | 用于输入、下拉和快捷键编辑 |
| 状态栏 | `#007acc` | 白字显示当前状态 |

输入框使用 `#3c3c3c` 背景，菜单和工具提示使用 `#252526` 背景，滚动条保持窄而低对比。默认工具栏与组件箱图标改用浅灰线稿，提高深色背景上的可读性。

主题只安装在 `app.main_window.MainWindow` 顶层窗口。画布中的设计窗口由 `RuntimeTree` 独立创建，不是设计器主窗口的后代，因此用户为项目设置的背景、文字和控件颜色不会被工作台主题覆盖；独立预览和 Python 导出也不安装该主题。

实现位于 `app/designer_theme.py`，由 `app/bootstrap.initialize()` 安装。回归检查位于 `tests/test_designer_theme.py`：

```powershell
python -X utf8 -m pytest tests/test_designer_theme.py -q
```

检查内容包括主题重复安装、浅色图标可见性、设计器识别，以及运行时窗口不受主题过滤器和样式表影响。
