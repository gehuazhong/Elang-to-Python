## 已复现并修复

| 问题 | 触发与影响 | 修复行为 |
| --- | --- | --- |
| 外观修改重建集合内容 | 列表框、表格、树形框、超级列表框和组合框修改颜色等外观时，条目被清空重建，运行时编辑及当前选择丢失 | 用内容快照判断是否需要重建；颜色、列宽、行高和表头变化复用现有条目，内容真正改变时仍完整更新 |
| 树展开状态被反复重置 | 修改树的外观会重新应用默认展开设置，覆盖用户刚折叠的分支 | 只在内容、模型或“展开”设置改变时重新应用；普通树形框和模型树视图共用规则 |
| 超级列表框勾选被重置 | 修改外观、列宽或行高时，运行时勾选恢复成设计初始值 | 内容或勾选设置未变时保留勾选；显式修改勾选、可编辑等设置仍即时生效，运行时新增行也能保留 |
| 默认目录损坏阻断操作 | 配置中的目录变成数字、列表或无效路径，打开、保存、导出入口抛出异常 | 统一校验目录，无效或已不存在的目录回退到用户目录；有效目录继续保留 |
| 恢复服务保留文档引用 | 服务关闭后仍保留文档监听和监视记录；写入期间完成保存并立即关闭时，归档回执可能尚未处理 | 关闭时停止调度、等待当前写入、解除监听并清空记录；保留未保存快照，归档已保存快照，支持重复关闭 |
