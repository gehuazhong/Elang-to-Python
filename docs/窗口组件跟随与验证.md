# 窗口组件跟随与验证

本版为 0.7.3，在窗口属性提供“组件随窗口缩放”开关。未启用时仍使用固定位置和尺寸；默认关闭，兼容现有项目。无需给每个组件逐个配置。

## 操作与语义

点击画布上方“窗口属性”，在“窗口”组勾选“组件随窗口缩放”，再拖动设计窗口右边、下边或右下角。窗口边框和后代组件立即预览新尺寸，松开只提交一次命令；按退出键取消，撤销恢复整个窗口及所有后代。修改窗口宽度和高度属性也生效；修改窗口屏幕位置不改变组件。

勾选或取消开关本身不移动组件。关闭后继续使用当前设计的位置和尺寸。窗口边框为“固定边框”时，预览与导出的运行窗口仍遵守禁止用户拉伸的设置。

按工作区宽高变化分别计算比例，因此窗口只加宽时只调整横向位置和宽度。分组框与边框容器保留设置的内容边距，后代相对新的内容区缩放。选择夹保留页签高度，各页都参加计算，包括当前未显示的页面。普通隐藏或设计锁定的后代也遵守窗口级跟随，锁定仍用于防止直接操作。

字体与字号保持用户选择，不跟随比例变化。工具条、状态条仍由窗口固定挂接并保持高度；时钟和通用对话框没有矩形，不参加计算。列表行高、表格列宽等内部内容属性保持原设置；该功能调整组件外部矩形，不是把整个应用截图拉伸。

最小有效尺寸继续生效：选择夹至少六十四像素，容器尺寸不能被内容边距占满；其他控件至少一个逻辑像素。极小窗口可能裁切组件，不保证任意缩小后文字和内容仍能完整显示。本轮提供按比例跟随，不包含单组件靠右、靠下锚定规则或自动布局。

运行期间始终以当前导出的设计基准重新计算，连续拖动不会把上次舍入结果作为新基准；恢复设计尺寸可恢复原几何。画布每次完整提交后形成新的设计基准，整数像素取整可以通过撤销准确恢复。独立调整某个容器的设计尺寸仍沿用原来只改变容器、不自动缩放后代的规则。

## 实现与文件

| 文件 | 职责 |
| --- | --- |
| widgets/builtin.py、panels/properties.py | 窗口布尔属性及完整中文勾选行 |
| layout/scaling.py | 不依赖 Qt 的比例计算与嵌套内容区规则 |
| layout/runtime.py | 运行窗口事件适配，每次使用固定设计基准 |
| core/window_scaling.py、core/commands/nodes.py | 模型与构建计划转规则，几何变化纳入同一命令 |
| runtime/builder.py、runtime/appearance.py、runtime/preview.py | 运行模式装载、释放及中文错误反馈 |
| designer/canvas.py | 临时渲染、取消还原与松开提交 |
| codegen/generator.py、codegen/publisher.py | 导出相同规则与运行适配，保留业务文件 |
| tests/test_window_scaling.py、tests/check_window_scaling.py | 数据、画布、实际运行、独立导出和桌面验证 |
| app/release_check.py、release/uiplay.spec、scripts/build_release.py | 便携包中的开关、撤销及实际导出缩放验收 |
| examples/窗口组件跟随示例.uipro | 开关已开启的嵌套示例 |

项目继续使用第二版 JSON，主窗口属性新增 `scale_children` 布尔值。旧文件缺失此值时视为关闭。现有注册机制、保存备份及命令历史沿用；未新增第三方依赖。`layout` 包的纯计算入口不加载 Qt，模型层保持独立。

## 验证命令

```powershell
python -X utf8 main.py "examples/窗口组件跟随示例.uipro"
python -X utf8 -m pytest -q tests/test_window_scaling.py
python -X utf8 -m pytest -q
python -X utf8 -m tests.check_window_scaling
python -X utf8 main.py --release-check reports/源码交付检查_0.7.3.json
```

桌面报告与截图使用 reports/窗口跟随_100_ 和 reports/窗口跟随_150_ 前缀。高显示缩放时操作系统可能限制顶层窗口大小，组件按实际内容区计算；检查同样依据系统最终尺寸。显示缩放启动检查不等于真实多屏移动或动态系统缩放验收。

## 本机验证结果

验证日期为 2026 年 11 月 7 日，环境为 Windows、Python 3.11.8、PySide6 6.11.1。专项十二项通过；与原有窗口外观、字体选择和缩放手柄合并的九十五项回归通过。最终全量五百六十五项通过，耗时九十七点九八秒。

设备像素比 1.0 与 1.5 下的真实窗口检查均通过，覆盖窗口属性开关、实时拖动、一次撤销、隐藏页面、嵌套分组框、运行时放大缩小和还原。旧缩放手柄、分页及易语言基础组件桌面检查通过。源码交付报告 reports/源码交付检查_0.7.3.json 通过，包含三十三类组件、跟随开关、保存加载、实际导出窗口拉伸与独立预览启停。
