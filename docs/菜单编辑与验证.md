## 操作

从“工具 → 菜单编辑器”或窗口属性中的“编辑菜单…”打开。已有菜单可双击画布菜单栏、双击对象树中的菜单，或右键选择“编辑菜单…”。

左侧显示菜单树，右侧设置当前菜单的标题、名称、代码名称、快捷键、状态提示、可选中、选中、禁止、可视、分隔线和“连接被单击事件”。

- 增加同级：在当前项后增加菜单；空项目创建第一个顶层菜单。
- 增加子菜单：在当前项内增加一级，自动生成下拉菜单。
- 上移/下移：调整同一级的显示顺序。
- 右移：成为上一项的子菜单；左移：移到父菜单后，返回上一层。
- 分隔线：点击“插入分隔线”，勾选“分隔线”，或将标题设置为 `-`。顶层不能使用分隔线。
- 标题中的 `&` 设置访问键，例如 `文件(&F)`；快捷键输入框直接按组合键，可点击清除按钮取消。
- “选中”自动开启“可选中”；运行时点击会切换勾选状态。“禁止”使菜单不可操作；“可视”关闭后运行时隐藏，对象树和编辑器中仍可修改。

确定后整次提交，一次撤销恢复整个菜单编辑前的状态。取消不修改项目。无效名称、重复快捷键或非法层级会就地提示，保留输入。删除最后一项并确定会移除空菜单栏。

菜单项会出现在对象树中。选中后，在属性面板“事件”组勾选需要的事件；取消勾选只断开连接，保留处理函数身份。分隔线不连接事件。预览只报告触发；运行导出项目才执行自己的业务函数。

## Python 扩展

菜单模型使用 `builtin.menu_bar` 和 `builtin.menu_item`，Qt 对应 `QMenuBar` 和 `QAction`；带子项的菜单自动关联 `QMenu`。项目继续使用原有 schema 2。

导出后通过 `window.controls["代码名称"]` 访问菜单项。例如示例中的 `window.controls["menu_details"].setChecked(True)`、`setEnabled(False)`、`setVisible(False)`、`setText("新标题")`。修改代码名称后，需同步更新自己的业务引用。

被单击事件对应 `QAction.triggered`，事件函数接收 `window` 和 `checked` 布尔值。将业务写入 `event_handlers/on_…_clicked.py` 的已有函数；初始化放在 `handlers.py`。再次导出保留这些文件。`generated/<版本>/menus.py` 负责菜单组装，无需手改。

## 示例与范围

`uidemo/05_菜单编辑示例/菜单编辑示例.uipro` 包含文件、视图、帮助、三级子菜单、分隔线、禁止和隐藏菜单、勾选项和快捷键。

```powershell
python -X utf8 uidemo/run_demo.py 5 --edit
python -X utf8 uidemo/run_demo.py 5
```

运行示例时，`Ctrl+N` 增加新建计数，`Ctrl+G` 切换说明，`Ctrl+Q` 退出。最近项目仅演示选择和提示，不打开或写入文件。

每个窗口最多二百个菜单项、八层层级。快捷键支持单组组合键，不允许重复；带子项的父菜单不设置快捷键。菜单通过专属编辑器创建，暂不支持跨项目复制、共享工具栏动作或右键弹出菜单的设计。
