# SVG 图标库

0.10.3 在 SVG 组件中提供 64 个内置线性图标，无需编写 SVG 或下载素材。

## 使用

1. 从组件箱拖入“SVG 矢量图”，或选择已有的 SVG 组件。
2. 在属性面板的“内容 → SVG 内容”点击“图标…”。
3. 按分类浏览，或输入中文、英文名称及关键词，例如“搜索”“放大镜”“search”“用户”“私信”。多个关键词以空格分隔。
4. 选择图标，设置六位颜色值及 0.5 至 4.0 的线宽。右侧同时显示浅色和深色背景预览。
5. 点击“确定”应用，点击“取消”保留原图形。应用是一次文档操作，可撤销和重做。

八个分类分别为导航、操作、文件、用户、消息、状态、媒体和工具，每类八个图标。图形是透明背景的矢量内容；需要保持原始比例时，在 SVG 组件的“外观”中开启“保持图形宽高比”，或设置相同的宽高。

图标内容直接保存在 `svg_data` 中。保存后重新打开仍可调整内置图标的颜色和线宽；预览和导出的 Python 程序都直接使用这份 SVG，不依赖图标库、字体、网络或素材路径。

打开 [常用 SVG 图标示例](../examples/常用SVG图标.uipro) 可以查看和复制全部图标。

## 源码与草稿

“SVG 源码”标签页保留手工编辑能力。切换标签页不会覆盖草稿；改写图形后按自定义 SVG 处理，颜色和线宽控件暂停使用，再次选择内置图标才会替换草稿。

搜索和切换分类只改变可见列表。当前选择仍显示在右侧，即使该图标不在搜索结果中。无结果时会显示提示。

无效 XML、错误的根元素、文档类型或实体声明、超过十万字符的文本会显示错误，保留输入并阻止提交。图形的实际可显示内容仍以 Qt SVG 支持范围为准。
