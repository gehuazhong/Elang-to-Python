# 界面优化与窗口属性

记录日期：2026 年 11 月 7 日。

本次在第二阶段骨架上改进配色、布局和窗口外观编辑。继续使用 PySide6，不增加第三方依赖。

本文保留首次界面优化的历史记录；后续工作台改版已使用中性灰配色与紧凑属性表，当前视觉以 `工作台视觉规范与验证.md` 为准。窗口属性的操作语义继续适用。

## 界面变化

- 统一浅灰蓝背景、蓝色选中状态、中文字体及线条图标；设计器样式表独立存放，不传入被设计窗口。
- 左上为组件箱，左下为对象树，右侧保留属性，底部缩小输出区。旧版停靠布局首次切换为新布局，后续保存新布局。
- 新建或打开项目时自动缩放到完整窗口；工具栏“适合窗口”和快捷键 `Ctrl+0` 可再次适配。缩放只影响查看，不修改项目尺寸。
- 画布显示标题栏、边框、阴影和窗口按钮。点击标题栏、空白区域或“窗口属性”按钮可选择主窗口；属性搜索可查找“边框”“背景”等中文属性。

## 可编辑属性

| 对象 | 属性 | 行为 |
| --- | --- | --- |
| 窗口 | 标题 | 同步更新画布标题栏和原生窗口标题 |
| 窗口 | 边框类型 | 标准边框、固定边框、无边框；固定边框约束运行时尺寸，无边框不显示标题栏 |
| 窗口 | 最小化按钮、最大化按钮、关闭按钮 | 映射到真实 Qt 窗口标志，并同步设计外框；无边框时禁用这些编辑项，固定边框禁用最大化 |
| 窗口 | 总在最前 | 写入 Qt 置顶标志；不会将设计器主界面设为置顶 |
| 窗口、工作区、按钮、标签 | 背景色、文字颜色 | 输入六位十六进制颜色或打开中文颜色对话框；重置后恢复默认或继承父对象 |
| 窗口、工作区、按钮、标签 | 字体、字号 | 字体留空、字号为零时使用默认或继承父对象；字号上限为 96 磅 |

所有新增属性均经元数据校验、文档命令和统一构建器处理，支持撤销重做与项目保存加载。旧项目缺少新属性时使用默认值，项目格式仍为第二版，不改写已有控件坐标。

窗口宽高表示内容区尺寸，不包含系统标题栏及外框。设计标题栏位于内容区上方，内容坐标原点保持为 `(0, 0)`。将组件拖到标题栏不会创建控件。

## 运行与验证

```powershell
python main.py
python -X utf8 -m pytest -q
python -X utf8 main.py --smoke-test
```

本轮完整回归为 127 项通过，耗时 9.71 秒，包含新增的 17 项边框、窗口按钮、颜色、字体、坐标、保存和界面联动检查。颜色对话框已检查确认提交与取消不提交两条路径。

实际桌面布局检查覆盖 1280 × 820 和 960 × 620，完整窗口均位于可见画布内，左右面板没有重叠；紧凑尺寸下可使用面板滚动条查看其余属性。

人工验证顺序：

1. 启动设计器，确认左侧对象树和右侧属性同时显示，窗口完整位于画布中。
2. 拖入按钮，点击画布顶部“窗口属性”，切换三种边框并观察标题栏及按钮。
3. 切换固定边框，确认最大化编辑项禁用；切换无边框，确认三个窗口按钮编辑项禁用。切回标准边框后恢复原设置。
4. 搜索“背景”，修改背景色，点击“重置”，再撤销与重做；搜索框清空后显示全部属性。
5. 修改标题、字号及尺寸，保存为测试项目并重新打开，确认外观和控件位置一致。
6. 调整画布缩放，按 `Ctrl+0`，确认完整窗口重新可见。

实际桌面截图保存在 `reports/界面优化_主窗口.png`、`reports/界面优化_无边框.png` 和 `reports/界面优化_紧凑布局.png`。

## 已知边界

画布中的外框为设计示意，不是操作系统直接绘制的非客户区。实际运行时的边框细节、按钮布局及置顶表现受操作系统和窗口管理器影响。设计状态下点击标题栏按钮会选中窗口，不会关闭或最小化设计文档。

本次外观优化没有扩展组件种类、事件编辑、代码生成或完整预览功能。后续交互优化已补充单对象缩放手柄，详见 `画布交互优化与验证.md`。独立窗口预览现已接入统一构建器并通过当前组件范围的验收，详见 `预览功能与验证.md`；生成器仍待实现。
