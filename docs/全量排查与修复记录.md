# 全量排查与修复记录

## 本轮目标

围绕当前已经实现的按钮、标签、属性面板、对象树、右键编辑、多文档、保存恢复和独立预览，检查正常操作与异常边界。沿用现有工作台视觉风格，重点解决输入丢失、编辑作用域、刷新状态以及故障恢复问题。

排查开始时已有 246 项测试通过。本轮通过新增用例复现缺陷后修复，最终完整回归为 270 项通过。

## 已修复的问题

| 问题与触发方式 | 修复后的行为 |
| --- | --- |
| 将名称改为空白，再左键选择另一控件、用对象树键盘切换或创建组件，未提交输入被替换 | 画布和对象树通过工作台提供的回调先提交属性；校验失败时保留原对象与输入，不创建新控件 |
| 非法属性阻止标签切换后，新增文档的后续面板绑定仍会清空输入 | 当前文档未改变时不重新绑定面板；新标签可保留在后台，当前输入保持可修正 |
| 回车提交属性后，面板重建导致输入焦点和光标丢失 | 同对象刷新恢复对应编辑器焦点、光标和文本选择，可以连续编辑 |
| 文本框有可撤销输入，但菜单只按文档历史决定撤销与重做状态 | 动作监听当前文本编辑器的历史和选择状态，文本快捷键使用原生控件处理；组件箱等非输入区域仍可调用文档撤销快捷键 |
| 输出区获得焦点后，执行撤销仍删除或移动设计控件 | 只读文本区禁用文本撤销，不向设计文档转发 |
| 修改属性后对象树重新展开全部分支 | 层级未变时只更新行文字；结构变化时也保留已有分支的展开状态 |
| 原生属性已更新，但某个控件绘制失败，下一次刷新误认为缓存仍有效 | 独立保留待绘制节点，只有缓存成功应用才移除；再次刷新会重试失败节点及尚未绘制的节点 |
| 缩放后的缓存分配失败，画布已经变换比例并向界面事件抛出异常 | 恢复原比例与变换，尝试恢复缓存，发出中文错误信息，工具栏同步实际比例 |
| 恢复目录无法创建时，打开流程留下已加入界面的文档，却释放其项目写锁 | 自动恢复初始化异常作为独立功能故障处理；打开与项目写锁继续有效，中文告知可手动保存 |
| 恢复扫描期间其他窗口归档文件，排序读取时间时异常中断 | 逐项捕获文件消失或读取失败，保留其余可用记录，并保证临时锁释放 |
| JSON 包含超长整数，泄露底层解析异常 | 转换为中文项目读取错误 |
| 剪贴板事件参数类型错误可能抛出底层异常，重复字段和未知顶层扩展可能被静默丢弃 | 复制前要求参数为数组，读取时拒绝重复字段及尚未支持的扩展 |

属性区增加中文就地错误提示；同一错误在失焦与切换校验中重复触发时，只记录一次。修正并成功提交后清除提示。

## 手动复查步骤

1. 创建按钮和标签，选择按钮，将名称改为空白，再点击标签或用对象树切换；应保留按钮选中和输入，并显示中文错误。
2. 将名称改为有效名称后按回车；光标仍在名称输入框，可以继续输入。
3. 在属性搜索框输入文字，分别使用撤销快捷键与编辑菜单中的重做；设计文档的控件和历史不应改变。
4. 点击输出区，再执行撤销；设计内容不应改变。回到画布后可撤销控件操作。
5. 折叠对象树工作区分支，通过属性面板修改当前对象；折叠状态应保留。
6. 右键复制、粘贴、删除，再撤销恢复；保存并重新打开后，控件属性应一致。
7. 按 `F5` 预览，修改属性后重新预览，再按 `Shift+F5` 停止。

绘制失败、恢复目录失权和扫描竞争等故障由自动化注入验证，无需手动破坏项目目录来测试。

## 仍有的限制

当前组件范围仍为按钮与标签；多选、层级重排、事件编辑执行、资源管理界面和代码生成尚未实现。本轮不将这些后续阶段功能记为已完成。

真实桌面检查使用 Windows 窗口和合成输入，未覆盖中文输入法组合态、物理鼠标、跨屏拖动及系统显示缩放切换。单个绘制缓存仍受现有像素上限约束；持续的内存不足仍可能导致显示无法刷新，但文档数据保留，可缩小尺寸或保存后重新打开。

恢复目录在建立会话时不可用会明确告知当前文档无法自动恢复；修复目录权限后重新打开文档才能重新建立该会话的恢复监视。已建立监视的写入失败仍按既有间隔重试。
