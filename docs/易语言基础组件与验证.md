# 易语言基础组件与验证

本版为 0.7.0 开发预览版，面向已习惯易语言拖放设计的个人开发者。本机验证环境为 Windows、Python 3.11.8、PySide6 6.11.1，验证日期为 2026 年 11 月 7 日。未新增运行依赖。

## 目标与组件范围

## 关键设计规则

选择夹使用 QTabBar 与 QWidget 页面组合实现固定内容坐标，避免样式改变导致模型位置和预览位置不同。页面是独立模型节点，挂接在 pages 位置，普通控件挂到具体页面。每个选择夹一至五十页，子控件坐标相对页面。页标题改变会同时使父选择夹的画布缓存失效，即时显示新标题。切换、增加、删除页面和完整控件树复制均使用文档命令；单独页面不提供复制，复制整个选择夹保留页面和后代。

工具条与状态条使用 QMainWindow 专属挂接位置，每窗各一个，不能当普通矩形控件嵌入分组框。内容区尺寸扣除两条高度；原生窗口、模型坐标及画布裁切一起更新。它们可以跨窗口复制，目标已有同类条时拒绝重复粘贴。

时钟与通用对话框是真正的非可视对象，模型没有画布几何。画布下方的标记仅供选中、编辑、复制和删除，不会出现在生成的应用中。时钟在全部运行对象创建后才启动，设计阶段保持停止。预览关闭时停止时钟并释放打开的对话框。高频时钟仅合并日志提示，不丢弃实际周期信号。

通用对话框以非阻塞方式打开，只允许同一组件同时存在一个对话框。选择完成返回文件路径列表、颜色字符串或中文字体描述；取消发出取消事件。设计时可通过下拉框选择触发按钮。删除该按钮会在同一撤销命令中清除绑定；单独复制对话框时清除外部按钮引用并提示，粘贴后可重新选择按钮。

图片导入通过 Qt 读取后转换为受限静态快照，嵌入组件属性，项目不依赖原图片路径。代码导出把图片写入生成版本的 assets 目录，并以模块所在目录解析相对路径。源文件最大十六兆字节，单张快照最大两兆字节，边长最大四千零九十六像素，总像素最大八百万。动图只导入首帧；旧式顶层外部资源清单尚未接入，不会静默遗漏导出。

图片框的内容裁切与边框绘制分开，避免导入图片后边框被一同裁掉。专项测试实际读取等比缩放、拉伸和居中三种模式下的四边与中心像素，并验证关闭边框后的显示。

超级列表框使用 QTreeWidget 的平面报表适配，不与普通表格混为一个组件。默认整行选择，可显示复选框、拖动列顺序、按列排序和设置行高。表项数据通过中文表格编辑器修改；已勾选行是从一开始的行号。修改表项数量后会移除无效勾选引用，可整体撤销。运行时排序、选择与编辑不回写设计项目。

## 运行和验收

```powershell
python -X utf8 main.py "examples/易语言基础组件示例.uipro"
python -X utf8 -m pytest -q
python -X utf8 -m tests.check_easy_widgets
python -X utf8 main.py --release-check reports/源码交付检查_0.7.0.json
python -X utf8 scripts/build_release.py
```

1. 打开示例，查看工具条、状态条和画布下方时钟、通用对话框。
2. 单击选择夹第二页，查看画板；撤销后回到第一页。
3. 右键选择夹添加页面，在对象树选择页面修改标题，再拖入控件。删除页面可整次撤销。
4. 复制整个选择夹并粘贴，确认全部页及后代保留；逐次删除、撤销和重做。
5. 选中图片框，导入图片并保存项目；原图片不在原路径时仍可显示。导出后保留整个生成目录。
6. 按 F5，点击“选择文件”验证通用对话框；观察时钟周期事件，切换第二页实际绘画。
7. 在超级列表框勾选、选择表项，启用列排序或调整行高；运行状态不污染设计文件。
8. 导出到新目录，按生成的使用说明运行；业务在 handlers.py 中接入，重复导出保留该文件。

真实桌面报告为 reports/基础组件_桌面检查.json，工作台、预览、时钟属性、画板页和通用对话框截图均以“基础组件_”开头保存。该检查使用 Windows 平台插件与合成输入，不等于物理输入法、多屏及不同显示缩放验收。

## 已知边界

本轮交付十六类基础组件的可用实现，未宣称与易语言全部组件属性和方法兼容。超级列表框目前是报表模式，尚无大图标、小图标及虚拟数据模式；单次表项编辑最多二百行、五十列。工具条暂不支持图片按钮、运行时拖动停靠和多条工具条。选择夹页签固定顶部；页签数较多时支持原生滚动，但画布尚无完整页签滚动编辑工具，可通过“当前页”属性选择。

画板笔迹属于运行状态；设计时可配置底图，不提供持久化矢量绘图编辑器。图片是静态快照，没有集中资源库、动图播放或外部链接监视。通用对话框已有按钮绑定；任意信号到业务函数的可视化编辑仍未完成。菜单栏、自动布局、整组缩放、批量属性、对象树拖动改父和外部插件发现仍待后续实现。

单次剪贴板载荷最多八兆字节。带自定义事件声明的非可视及窗口条对象尚不能单独粘贴，会明确拒绝；普通容器内部连接仍按已有整树复制契约处理。

当前便携包仍是未签名开发预览版。仓库外解压和独立搜索路径检查不等同于另一台干净系统验证。
