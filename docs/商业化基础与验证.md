# 商业化基础与验证

本轮针对个人开发者，优先完成中文设计后带走源码、持续更新界面、交付可运行桌面程序的基础。当前版本为 0.3.0 开发预览版，尚不是完整商业正式版。

## 使用流程

1. 运行根目录 `main.py`，拖入按钮、标签、单行编辑框并修改中文属性。
2. 通过“文件 → 保存”保存 `.uipro` 设计项目。保存与代码导出各自独立。
3. 通过“文件 → 导出 Python 项目”或 `Ctrl+Shift+E` 选择导出目录。
4. 在导出目录执行 `python -m pip install -r requirements.txt`，然后执行 `python main.py`。
5. 在导出目录的 `handlers.py` 中编写业务，再次导出到同目录只更新生成版本。

属性面板“高级 → 代码名称”支持选中复制。默认新建的三个控件可分别通过 `window.controls["button_1"]`、`window.controls["label_1"]`、`window.controls["line_edit_1"]` 获取。代码名称由设计器维护，不与可修改的中文显示名称混用。

例如，放置这三个控件后，可以将业务文件写为：

```python
"""读取输入，并在单击按钮后显示字符数。"""

from PySide6.QtWidgets import QLabel, QLineEdit, QMainWindow, QPushButton


def connect_events(window: QMainWindow) -> None:
    controls = getattr(window, "controls")
    button = controls["button_1"]
    label = controls["label_1"]
    editor = controls["line_edit_1"]
    if not isinstance(button, QPushButton) or not isinstance(label, QLabel) or not isinstance(editor, QLineEdit):
        raise RuntimeError("示例需要按钮、标签和单行编辑框各一个。")

    def show_count() -> None:
        label.setText(f"共 {len(editor.text())} 个字符")

    button.clicked.connect(show_count)
```

这是导出应用中的 Python 信号绑定。设计器内的可视化中文事件面板仍未实现，设计器的预览不会执行此业务文件。

## 导出契约

```text
导出目录/
├── main.py                       首次安装的稳定入口
├── handlers.py                   用户维护的业务文件
├── requirements.txt              首次安装的依赖说明
├── 使用说明.md                    首次安装的中文说明
├── .uiplay-export.json           首次导出的所有权记录，支持中断重试
├── current.json                  当前完整版本指针
└── generated/
    └── 内容摘要/
        ├── ui_main.py            窗口类、控件创建、属性与焦点顺序
        ├── application.py        中文翻译和应用外观
        └── appearance.py         与预览共用的外观及窗口属性适配
```

同一输入产生同一版本内容。新文件全部准备好后才原子替换 `current.json`；启动时只读取一次指针。已发布旧版本保留，不自动删除，首次初始化中断后允许同项目重试。

业务文件不执行、不改写，只检查编码、语法和一个接收窗口参数的普通 `connect_events` 入口；不支持为该入口添加装饰器、可变参数或改成异步函数。其他业务函数和本地模块可自由维护。导出期间业务文件发生变化会中止发布，保留用户修改。

异项目目录、被修改的稳定入口或自动生成文件、文件写锁冲突、非法类名会明确阻止导出。未知节点、属性、扩展、事件配置、资源、自动布局、非零布局边距及未知生成设置不会静默遗漏。当前固定导出 `main.py` 入口；入口协议升级须单独迁移或选择新目录。

文件锁只协调采用本协议的导出器，不能阻止任意外部程序同时写文件。故障注入验证的是本地文件系统上的软件中断，不等同于物理断电或网络共享盘保证。

## 交付与排障

“文件 → 最近项目”只记录成功打开或收到成功保存回执的项目，最多保留十条，支持清空记录。不存在的文件不会悄悄改写记录或新建项目。“视图 → 恢复默认布局”恢复各面板和工具栏，不改变设计文档。

启动入口可接收多个项目路径。修复了恢复主窗口尺寸后又被入口强制重设的问题。窗口化便携包内，预览复用自身可执行文件的专用子进程入口，通过父进程管道收发消息；不依赖外部 Python，不创建额外控制台。

日志采用每文件两兆字节、三份历史备份的滚动策略。未处理的界面异常与线程异常写入本地日志，中文摘要显示在输出中。“帮助 → 导出诊断包”只导出环境、项目数量、预览状态及未处理异常的位置，不收集项目文本、业务代码、完整路径或日志全文，也不会上传。详细日志仍在当前用户数据目录中，排查时由用户决定是否提供。
