# 兔子工具个人中心

参考 `reports/QQ20261109-153349.jpg` 制作的 1000 × 654 桌面界面。182 像素深灰侧栏、黑色内容区、用户资料和三张 144 × 144 收藏卡片均按参考图的位置排列。头像截取自所提供的参考图，兔子标志和导航图标重新绘制。

- `兔子工具个人中心.uipro`：设计器可打开的项目，文字、图片、按钮和图标分别可选中编辑。
- `Python导出/main.py`：完整独立运行入口，依赖见同目录的 `requirements.txt`。
- `预览.png`：设计项目运行时布局截图。
- `运行预览.png`：已连接业务交互的导出窗口截图。
- `设计器.png`：在本项目设计器中打开的截图。

在项目根目录运行：

```powershell
python -X utf8 uidemo/run_demo.py 7
python -X utf8 uidemo/run_demo.py 7 --edit
```

导航可切换标题、收藏分组和卡片名称。“修改资料”支持昵称校验、保存、取消并同步标题栏昵称；资料仅在当前运行中保留。卡片和设置按钮打开本地演示提示。标题栏支持拖动窗口，右上角支持最小化和关闭。

设计器 F5 预览显示布局和原生控件，不执行独立导出中的业务函数。完整交互请使用上述运行命令。业务代码位于 `Python导出/profile_demo.py`，重新导出会保留它。

修改设计文件后可以重新导出。制作源码位于 `../profile_example.py`；重建命令 `python -X utf8 uidemo/build_examples.py --only 7` 优先读取已有设计文件，不覆盖手动修改。
