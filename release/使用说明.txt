中文界面设计器 0.10.1 开发预览版

启动
双击“中文界面设计器.exe”。请保留整个目录及其中的 _internal 文件夹，不要只复制可执行文件。
也可将界面项目拖到可执行文件图标上，或从“文件 → 打开”选择项目。
本版修复打开与保存窗口的扩展名筛选，项目文件不再被错误过滤；打开时可切换“所有文件”查看其他文件，选中后仍会校验项目格式。
便携包运行设计器无需另装 Python；应用设置、日志和恢复副本仍保存在当前用户的数据目录。

快速开始
本版修复菜单项目预览时报“项目包含当前预览尚未实现的组件”的问题；仅设置菜单、没有普通控件的项目也可直接按 F5 预览。
“工具 → 菜单编辑器”或窗口属性中的“编辑菜单…”打开易语言式菜单设置。左侧编辑菜单树，右侧设置标题、名称、快捷键、选中、禁止、可视及事件连接；上移/下移调整顺序，左移/右移调整层级，标题填 - 表示分隔线。
点“确定”整次提交并支持一次撤销；取消不修改项目。双击画布菜单栏或对象树菜单也可进入编辑器。按 F5 实际操作菜单，导出后在 event_handlers 对应函数中写业务。菜单示例位于“示例/菜单编辑示例.uipro”。
属性区的鼠标滚轮用于浏览，不会误改尺寸、数值、日期或切换下拉选项，即使输入框已有焦点也一样。打开下拉列表后仍可滚动浏览选项。
数值可用键盘、输入框旁的箭头或直接输入修改，按回车或离开输入框应用。未提交的步进数值不会被保存回执等后台刷新清空。
启动时按当前屏幕的可用范围调整窗口。高缩放且逻辑高度较小时，新工作台把组件箱和对象树合并为标签区，收起输出面板，为画布和属性保留空间，字体不变。已有有效布局优先保留；输出可从“视图”打开，发生错误时会自动展开。
新建和打开项目默认按 100% 原始大小显示，设计窗口位于画布左上方。超出工作区时使用滚动条浏览，不会自动缩小文字。
工具栏“原始大小”或 Ctrl+0 恢复 100% 并回到左上方。“查看全貌”或 Ctrl+9 临时缩小以查看完整设计。
普通滚轮浏览画布；按住控制键滚动可围绕鼠标位置缩放。缩放只改变查看比例，不修改窗口尺寸、字体或生成代码。
从左侧拖入组件，在右侧修改中文属性；现支持三十七类组件。
富文本编辑框支持纯文本和 HTML 初始内容；文本浏览器支持链接事件。设置标签“文本格式”为富文本后，也可点击链接或选择文字。
字体组合框可选择本机字体、字体范围和文字系统；快捷键编辑框录入单组组合键，需在业务中应用到对应动作。预览中可录入 Esc，Shift+F5 仍停止预览。
按钮支持图标、图标宽高和显式快捷键；图标宽高为零时保持组件原生尺寸。菜单项也支持图标和提示文本。
分组框可开启“显示选择框”；取消组选中会禁用组内组件，重新选中仍保留子组件自身的禁用设置。
复制带快捷键的控件时，副本仅清除与目标窗口冲突的快捷键，并显示状态栏提示；跨项目无冲突粘贴保留快捷键。整个粘贴可一次撤销。
新增示例位于“示例/文本与输入组件.uipro”，可直接打开继续设计。源码 uidemo 第六份包含同步预览与保存草稿的演示业务。
选择组件后展开“事件”：勾选显示“已连接”，取消勾选显示“未连接”；默认不连接。可搜索“被单击”“文本改变”等中文事件名。
事件状态随项目保存，支持撤销、重做和复制；再次预览后采用最新勾选状态。未勾选仍保留组件原生行为，但不连接对应事件处理函数。
可视组件支持鼠标、键盘、焦点、显示隐藏、关闭、重绘和拖放事件；时钟、通用对话框提供适用的专用信号。预览只显示勾选事件的触发提示，不执行导出目录中的业务代码。
设置程序图标时，点击“窗口属性”，在“窗口”组的“程序图标”一行点击“选择…”。支持 ICO、PNG、JPG、BMP、GIF 和 WEBP；多尺寸 ICO 使用分辨率最高的一帧，动图使用首帧。
图标缩略图和画布标题栏立即更新，按 F5 可查看运行窗口图标。“清除”恢复默认，选择和清除都支持撤销重做。
图标快照随项目保存，删除原图后仍可使用；导出代码会携带图标资源，请保留完整导出目录。旧项目未设置图标时继续使用默认值。
需要组件随窗口一起拉伸时，点击“窗口属性”，在“窗口”组勾选“组件随窗口缩放”。默认关闭；开启后按比例改变组件位置和大小，包含分组框与选择夹内部组件，字号和工具条、状态条高度保持原值。
画布拉伸即时预览，松开后整次提交并可撤销；预览和导出运行使用相同规则，运行时拉伸不会回写设计项目。固定边框窗口仍不能由用户拉伸。
这是窗口级的按比例跟随；独立调整某个分组框大小时不会自动缩放后代。极小窗口下组件保留最低有效尺寸，放不下时由父容器裁切。
“字体”和“字号”直接下拉选择，不需要手填。字体列表来自本机字库，中文字体优先并按对应字形显示；字号以磅为单位，常用值在前，其余一至九十六磅整数在后。
选择“继承默认”跟随所属容器或系统；选择立即生效并可撤销。项目引用的字体本机没有时会标明“本机未找到”，保留原设置。
“常用组件”优先列出易语言用户熟悉的十六类基础组件，编辑框、时钟、选择夹、工具条和状态条按常用名称显示。
“帮助 → 组件支持清单”可搜索组件、属性和事件，明确查看已接入和待接入能力。
多行文字、组合框和列表项目、表格内容、树形内容通过属性右侧“编辑…”打开中文编辑窗口。
表格支持增删行列和修改列标题；树形内容支持同级、子级和顺序调整。点击确定才修改项目，取消保留原内容。
表格的“表格内容”和超级列表框的“表项与列”支持逐列设置宽度：在编辑窗口下方选择“当前列”，输入“列宽”，也可直接拖动列标题边界。
例如 ID 列设为 56，名称列设为 160，说明列设为 280；单位为逻辑像素，显示缩放不会改变保存值。“适应内容”按当前内容计算宽度，“恢复默认”让该列跟随组件的“默认列宽”。
列宽与行列内容一起保存、复制和撤销，预览及导出保持一致。末列设置明确宽度后不自动填满；要让末列填满剩余空间，请恢复该列默认并开启“末列填满”。
右键控件可复制、粘贴、删除；拖动手柄调整尺寸；控制键加撤销键撤销操作。
按住控制键或上档键单击可增减选择；从画布空白处拖出矩形，选择完全包含的控件。
多选后可整组拖动、复制、粘贴、删除；全选快捷键为 Ctrl+A。输入框中的快捷键仍只处理文字。
“排版”菜单提供六种对齐和横向、纵向等间距；对齐以最后单击的控件为准，等间距至少选择三个控件。
多选时显示每个控件的轮廓，不提供整组缩放和批量属性修改。每次批量操作可一次撤销。
按 F5 预览，按 Shift+F5 停止预览。

容器与日期
先拖入分组框或边框容器，再向其内容区拖入组件，即可建立父子关系。
子控件的位置以容器内容区为原点；修改内边距会改变内容区。父容器移动时全部子控件随之移动。
“所属容器”属性和右键“移入容器”可调整父级，保持窗口内位置；超出内容区时向内调整，放不下会明确拒绝。
复制容器会复制全部后代；键盘粘贴容器默认建立同级副本，右键粘贴可指定容器和落点。
容器缩小后，超出内容区的子控件会被裁切，不会自动改动其尺寸；锁定父容器会阻止后代的几何与结构操作。
日期支持闰年和范围校验；小数输入最多六位小数，降低精度会联动四舍五入范围、当前值和步长，整次可撤销。
日期时间表示界面显示的日历字段，不包含时区换算业务。液晶数字目前仅支持整数。
打开“示例/容器与日期示例.uipro”可直接体验本版能力。

易语言基础组件
打开“示例/易语言基础组件示例.uipro”，可体验十六类基础组件。
选择夹默认两页。直接单击画布上的页标题切换，再拖入控件；右键可添加页面或删除当前页及其控件，整次可撤销。
修改页标题请在对象树选择对应页面，在属性中修改“页标题”。选择夹至少保留一页，最多五十页；复制整个选择夹会保留全部页和子控件。
时钟和通用对话框出现在画布下方的非可视组件区，也可在对象树选中、编辑、复制和删除。
时钟周期以毫秒计，最小一毫秒；只在预览和导出运行时启动。启用、自动启动和只触发一次分别控制运行方式，周期事件提示按秒合并。
通用对话框支持打开单文件、多文件、保存文件、文件夹、颜色和字体。“触发按钮”选择现有按钮后，预览时点击即可打开。
工具条固定在窗口顶部，状态条固定在底部，每个窗口各一个；高度和内容可以编辑。
图片框在“图片”属性中选择文件，支持等比缩放、拉伸和居中。画板的“底图”同样可以导入。
导入结果是静态图片快照，随项目保存；动图只导入首帧。图片源文件最多十六兆字节，转换后的单张快照最多两兆字节。
图片尺寸每边最多四千零九十六像素，总像素最多八百万。导出时会生成 assets 图片目录，请保留完整导出项目。
超级列表框目前是报表式：多列、整行选择、多选、勾选、排序、行高及表项编辑。已勾选行使用从一开始的行号，每行一个。
画板在运行时支持鼠标绘画；绘画内容不回写设计项目。业务代码可调用 draw_line() 和 clear()。

保存与导出
设计项目读写统一限制为三十二兆字节；超出时停止保存并保留原文件与备份，请减少或压缩图片等内容后再保存。
“保存”生成 .uipro 设计项目。“文件 → 导出 Python 项目”生成独立源代码。
导出的 main.py 是入口；勾选事件的处理函数位于 event_handlers 目录并自动连接，窗口初始化和手动连接仍可写入 handlers.py。
对应函数的第一个参数为 window，其余参数为原始信号参数；通过 window.controls[代码名称] 访问组件。鼠标、键盘等通用事件传入 Qt 事件对象，返回 True 可阻止默认处理。
再次导出到同一目录不会覆盖已有业务文件，只补充新勾选事件的函数文件。取消勾选后不自动连接，保留已有文件，重新勾选继续使用原代码。
在代码运行环境安装导出目录 requirements.txt 中的依赖，再运行 main.py。
修改界面后可再次导出到原目录。请不要手工修改 generated 中的文件或 current.json。
请同时备份设计项目和整个导出目录；仅保存代码不能恢复画布编辑状态。

排查问题
面板关闭或移动后，可选择“视图 → 恢复默认布局”。
“帮助 → 导出诊断包”只保存环境、运行状态及未处理异常的代码位置摘要，不含项目、业务代码或日志全文，不会上传。

当前范围
已支持按钮、标签、单行编辑框、多行编辑框、组合框、选择框、单选框、数值输入框、进度条、滑块、列表框、表格、树形框，以及富文本编辑框、文本浏览器、字体组合框和快捷键编辑框。
新增分组框、边框容器、旋钮、滚动条、小数输入框、日期编辑框、时间编辑框、日期时间编辑框、日历、工具按钮、命令链接按钮、液晶数字。
支持窗口属性、单对象缩放、多选与批量排版、多文档、保存恢复、预览和代码导出。
支持粗体、斜体、下划线、删除线、布局方向、状态提示，以及各组件对应的内容、数值、选择、边框和行为属性。
缩小数值范围会调整当前值；删除列表项目会调整选项编号；选中互斥单选框会取消同容器其他单选框。关联变化可一起撤销。
本版新增画板、图片框、选择夹、时钟、通用对话框、超级列表框、工具条和状态条。
菜单栏与多级菜单已接入，窗口最多二百个菜单项、八层层级。快捷键为单组组合键，不能重复；含子菜单的父项不设置快捷键。菜单通过专属编辑器创建，暂不提供跨项目复制。
滚动容器、集中资源库、自动布局、整组缩放、批量属性编辑、对象树拖动改父和外部插件加载尚未完成。
事件组支持勾选连接、取消连接、预览提示和导出处理函数；通用对话框可绑定按钮。内置业务代码编辑器尚未提供。超级列表框尚无大图标和小图标模式。
此包为本地验证的未签名开发预览包，尚未完成独立干净系统、物理输入法及多屏缩放验收。
第三方信息见“第三方说明.txt”和 _internal/许可证。发行主体、自有代码授权及签名尚未配置。
